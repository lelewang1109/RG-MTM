## 清理与版本选择依据

依据实际TeX递归引用、FIGURE_INDEX、源结果manifest和逐文件SHA256确定版本，不按文件修改时间简单取最后一份。

- `04-paper`旧无图/有图稿、此前Overleaf包、旧发布PDF、旧流程图PPT和output的v2/v3/v4草稿移出当前投稿材料。
- 10个不参与当前编译的TeX模块、21个未引用旧图，以及过期/一次性改稿脚本移入归档。它们不再作为活动编辑入口。
- Benzene电子密度试跑、二维圆柱、旧Benzene三维源搜索、旧Tangaroa12帧和ECNR36帧结果移出投稿。正式Benzene使用21个静态二维重建电势截面，正式Cylinder是真正三维方柱102帧。
- 依据四份冻结PM2.5协议，保留实际使用的120天源NC，另外246天约5.55GB移至“其他研究数据”。退役OISST源、旧12帧缓存、3帧smoke地图、旧生成数据和不完整下载片段也已归档。
- 图1固定x方向与数据方向是两个研究设置，移至 `paper/supplementary_variants/` 作为补充候选，保留冻结实验数据。
- 只删除系统/解释器可再生缓存，以及经过字节校验后由链接替代的重复实体。研究原始材料与旧稿移至可恢复归档，没有批量永久删除。

“其他”约17GB，包含RA-MTM研究、约13GB非本次投稿数据及约2.9GB历史稿/构建记录。这是与当前材料分离的可恢复归档，本轮未以清理为由销毁研究记录。

## 去重及必要保留例外

81个相同实体改为相对链接，移除约55.3MB重复字节：26套图的PDF/PNG/SVG、正文和附录PDF兼容路径，以及一份相同PM2.5处理NC。修改了同步脚本的同源复制处理，避免SameFileError。

以下属于必要保留，不视为多个活跃版本：

| 保留项 | 原因 |
|---|---|
| 单图PPT、导出PDF/PNG/SVG、合并PPT | 编辑、论文排版、预览和整包交付职责不同；单图母版是唯一编辑入口 |
| 独立LaTeX ZIP | 必须包含实体图件与数值快照，脱离本工作区也可交付 |
| `code/results`与论文冻结evidence | 前者是实验原始记录，后者是独立论文包的证据快照；保持数值身份与来源，不混为另一实验 |
| `results/legacy_publication`、`results/archive/pm25_janfeb` | 原始manifest与177份数值溯源检查依赖它们；明确标记非当前稿、非新增结论 |
| Tangaroa原体、TTK树、完整地图与固定TTK二进制/源码 | 是不同计算层的复现与核验输入，不能只因同一数据集就删除；旧CMake绝对路径缓存单独归档 |
| 原README和代码修复前字节 | 放在“其他/归档/整理前说明”和“整理前脚本”，保留变更前依据 |
