## 1. 数据和评价的统一组织

Tangaroa和Cylinder均为三维空间输入；二维的是输出地图。可与二维输入使用同一套评价章节和同类指标表，数据总表仍必须写清维度、标量、静态/时变、处理设置。

拟保留的统一评价对象共9个：Storms、Wildfires、OLR、PM2.5、Ring、Tangaroa、Cylinder、Nucleon、Benzene。镜像运动控制另列为机制实验，Storms744小时图另列为可视化实例。

| 对象 | 输入与总体 | 在统一评价中的职责 |
|---|---|---|
| Storms / Wildfires / OLR / PM2.5 / Ring | 5个二维时序输入，共278帧 | 完整原有共享输入对照、精确小树前沿及跨领域结果 |
| Tangaroa | 300×180×120、201个真实三维速度模长场 | 多特征、较大问题、显著标量代价与投影限制 |
| Cylinder | 192×64×48速度场先算三维Q，再保留135×64×48子域，102帧 | 第二个三维标量；低价工作点、阈值饱和及非单调性 |
| Nucleon | 64×64，1个静态二维输入 | P改善合法布局，R与P完全重合的零额外收益例 |
| Benzene | 61×61，21个静态z截面 | 明确标记的重建电势实验；z不是物理时间 |
| 镜像运动控制 | 241×241，64帧，独立构造 | 成对距离不变而绝对参考位置变化的机制控制，不是拟删除的Gaussian主套件 |

组织上取消“先完整二维评价、后面再放一个三维评价表”的做法。相同指标的表格都按相同9个输入顺序列出。方法和参数差异写在协议及脚注，不通过分开摆放掩盖差异，也不把各总体合成一份总准确率。

### 推荐表格结构

1. **数据总表**：数据、来源/真实或重建、维度、标量、网格、帧/静态截面数、特征数、树与预处理。
2. **共同指标主表**：9个输入的 TMTM / ST-MTM / P / R20 NROE，以及R20的NMLE均值和最大值。未运行的ST-MTM记n/r，不补零。
3. **连续参考位移表**：同一9个输入的P/R20 E_pool和E_inf。统一使用连续布局、按特征帧加权的E_pool定义，不直接搬用旧三维Anchor MAE。
4. **运动表或主表的运动列**：7个时序输入的各方法错误数/N_clear；源空间维度按实际2D/3D标注。静态输入记不适用，投影真值作为独立控制保留，不能混用它的分母。

完整SNS/TW/TD、不同运动窗、完整方法和参数档位放附录。在没有补算的情况下，不为三维输入填写原本仅二维具备的这些指标。正文不必放一个过宽的单表；“统一评价”是相同定义、同一数据顺序和相同论证位置，不是把所有量挤进同一张表。

## 2. Gaussian的退出范围与同步工作

拟退出的是主套件中的 `gaussians`：64×64、64帧的本地Gaussian变体。退出理由应写为数据职责重叠、非原作者输入、在当前运动协议下没有可判定事件；不能把缺少事件写成一次失败的算法实验，也不能把移除后的改善说成新增性能。

保留独立镜像运动控制、Ring生成中的径向函数和其他数据的Gaussian平滑。不能通过全文删除“Gaussian”一词处理此调整。

只读核算结果：

- 核心时序套件：6序列342帧 → **5序列278帧**。
- R20精确小树前沿命中：339/342 → **275/278**；分项为Storms118/118、Wildfires28/30、OLR60/60、PM2.5 30/30、Ring39/40。
- 层次成本超过2%：五序列合计92/278；分项40、19、7、5、21帧。
- 五序列R20平均NMLE范围仍为0.86%—3.96%；**不能把它写成加入Tangaroa后全部数据的代价范围**，Tangaroa R20的均值为14.442%。

实施时应同步：投稿用数据成员、实验默认运行列表、验证中的统计断言、数据/指标表、所有含该数据的主附图、主附录文字、打包与索引。现有冻结原始结果保留为历史溯源，新投稿快照只筛选保留的数据；不能覆盖旧哈希清单来冒充原实验从未包含Gaussian。

## 4. 说明图放在哪些章节

- **统一评价章节**：9个数据总表 → 共同方法/指标与全部数值 → 位置/标量机制（图5）→ 绝对参考机制（图6）→ 参数与代价（新增图）。既有图4已解释方法，不在每个案例重讲算法。
- **案例解释章节**：Storms引用已保留图1；Wildfires讲伪运动和人工连接值；Tangaroa讲复杂三维冲突和高代价；Cylinder讲不同标量及低价/非单调工作点。按解释的问题组织，不再按二维/三维形成两套评价。
- **正文边界短段**：Nucleon零收益、OLR的P/R运动错误同为3/56、PM2.5仅7个明确事件、投影损失、求解界和重建来源。完整图和完整配置表在附录。

Tangaroa与Cylinder不需要从前面的二维指标体系另起一套。它们的源域物理距离按真实3D计算，投影运动另给分母；这个必要说明与统一评价组织并不冲突。

## 5. 如何选局部时刻，避免只挑有利图

现有冻结记录明确说明：Wildfires第18帧是在可连续追踪且有正收益的冲突中选H最大；Tangaroa第140帧是在合格冲突中选P→R最大误差下降最大。因此应称“用于解释机制的选定案例”，不能称无偏典型帧或中位性能。

建议统一采用：

1. 总览始终显示完整序列，不只取有改善的时间段。
2. 全序列统计含无改善、较差结果和界未闭合的数量；预览图不能代替完整剖面指标。
3. 机制示例可保留最清楚的冲突，但图注公开其选择规则，并报告标量代价。
4. 如需代表性例，在完整证据、可跟踪的合格事件中按预先固定的中位H或中位改善规则选；附录补最大代价、零额外收益和失败边界。
5. Cylinder首/中/末帧是均匀覆盖，不等于代表性能，也不擅自命名成物理形成阶段。补局部窗时先固定选取规则。
6. 同一案例使用相同特征ID、方向、标量尺度和源时刻；局部放大应标原区域；标量变化量以保存的完整地图测量。
