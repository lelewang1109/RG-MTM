# 当前论文贡献：统一位置—拓扑框架

论文名称：**Reference-Guided Merge Tree Maps: A Unified Position–Topology Framework**。

本次改稿把贡献组织为一个可以执行、解释和验证的体系：

1. **统一表达。**沿用参考位置、几何距离、时间运动、锚点偏心四项公式，保持共同变量、区间几何、求解器与绘制流程。通过参数限制得到拓扑—时间、拓扑—几何、参考保持、参考放松等工作区域。前两个区域表达TMTM、ST-MTM的核心设计偏好，称为inspired regimes。
2. **冲突解释与误差控制。**位置证书分离显示容量与层级约束的代价；最优屏障计算顺序改变所需的标量代价。真实拓扑预算ε与位置预算B共同定义可行布局，前沿和反向查询回答“需要付出多少拓扑代价才能达到位置要求”。
3. **同模型受控实验。**在相同输入、候选池、宽度、画布和绘制规则下改变参数；同时报告参考误差、几何距离误差、静止对齐误差、真实运动残差、连续拓扑误差和栅格误差。原生方法保留为独立比较对象。

## 公式与参数

目标为 λR ER + λG EG + λM EM(η) + λC EC。ER是锚点对参考位置的平方残差；EG是锚点间距离对支撑质心距离的应力；EM(η)比较实际显示位移与η倍的真实参考位移；EC是锚点与区间中心的偏心残差。各项按特征/配对/匹配数量取均值，并按统一画布长度平方归一化。

- η=0：时间对齐；η=1：跟随投影运动；中间值连续插值。
- ε：相对于固定标量范围的连续、带标签合并误差上限。
- B：相对于统一画布长度的参考位置误差上限；∞表示关闭。
- λR=0不会自动关闭有限B，二者必须分别声明。
- 旧κ仍只是可释放节点的父合并间隙阈值，不能改名当作真实输出误差上限ε。

当部分目标关闭导致解不唯一时，共同规则在主目标的零空间内选择紧凑区间中心对应的锚点，保证主目标值不变。这样避免自由坐标被求解器任意推到边界。该规则不使用参考位置，历史默认求解行为保留。

## 论证层次

- **严格论证：**固定顺序的凸性；固定候选池、前一帧位置和权重下的可行集合嵌套；最优位置前沿和反向查询的单调性；固定极值值的连续最优屏障；明确参数限制下参考项的关闭。
- **实验说明：**原方法与启发区域的相似程度；不同阈值下图像变化；实际参考、几何和时间指标如何折中。
- **当前不声称：**同一阈值恢复完整原生算法；候选搜索在池外全局最优；逐帧时序优化等于全序列最优；连续预算自动成为严格极值栅格图的同一预算。
