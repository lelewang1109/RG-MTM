## 0. 一句话

把一段时间的数据画成"时间 × 一条线上的位置"的合并树地图时，我们证明了"想保住层级关系，位置最少要偏多少"，给出达到这个最低值的画法，并在 7 组数据、917 帧上与 4 类已有做法逐一比较。如果用户允许层级有上限内的误差，位置可以更准，而所有改动都会标在图上。

## 1. 问题背景

### 1.1 什么是合并树

对一个标量场（比如气压场），从低往高"灌水"：每个极小值是一个"盆地"，水位升高时盆地会两两连通。记录"哪两个盆地在什么水位连通"，就得到一棵树，叫**合并树**。

- **叶子**：极值点（盆地底部），也就是特征，比如一个低压系统。
- **合并层级 $V_{ij}$**：叶子 $i$ 和 $j$ 连通时的水位，也就是它们最近公共祖先节点的值。
- 对"极大值"（如火灾强度、PM2.5 浓度峰值），把场取负，同样处理。

### 1.2 什么是合并树地图

TMTM（2023）提出：每个时间步，把合并树"拉直"成一条一维剖面，剖面上的盆地就是特征，盆地之间的"屏障"高度就是它们的合并层级；再把每个时间步的剖面竖着排开，横轴是时间。

于是每个特征成为一条横向的带，带的嵌套关系显示特征如何相连。这样一张静态图就能看到整个时间序列。

### 1.3 已有方法的问题

- **TMTM**：按树的遍历顺序排列特征，再让相邻时间步尽量对齐。纵轴位置没有物理含义。
- **ST-MTM**（2026）：加入特征之间的空间距离，让近的特征在图上也近。但它只保"相对距离"，不保"绝对位置"：整体平移或翻转后距离不变，位置却全错了。
- **Hovmöller 图**（气象常用）：纵轴就是经度，一看就懂，但完全没有层级信息。

**本文问的问题：** 能不能让纵轴贴近一个真实坐标（比如经度），同时层级一点不错？最多能贴近到什么程度？

首图（图 1）就是例子：1999 年 12 月 17 日 12 时北大西洋的五个低压 A–E，按西到东标字母。TMTM 式的画法把五个都挤在纵轴中部五分之一的范围里；本文的画法让它们基本按东西顺序排开，只有 C 被层级关系"逼"着偏离。

## 2. 基本概念和记号（论文表 1）

| 记号 | 大白话 |
|---|---|
| $T_t$ | 第 $t$ 个时间步的合并树 |
| $V_{ij}$ | 叶子 $i,j$ 的合并层级（水位） |
| $\Delta_F$ | 整个序列的数值范围（最大值 − 最小值），用来把误差换成百分比 |
| $q_i$ | 叶子 $i$ 的**参考坐标**：极值点位置在一个固定方向上的投影（比如东西方向），整段序列方向不变 |
| $L$ | 画布长度（世界单位），所有位置误差都除以 $L$ 变成百分比 |
| $\pi_t$ | 叶序：特征在纵轴上从下到上的排列顺序 |
| $x_i$ | 叶子 $i$ 在图上的锚点位置（盆地底部画在哪里） |
| $W_i$ | 叶子 $i$ 占据的区间宽度，与其支撑区域大小（面积或体积）成正比 |
| $g$ | 相邻区间之间的间距 |
| $H_i=\rho W_i/2$ | 锚点松弛：锚点可以在区间中心左右 $H_i$ 范围内移动 |
| $\psi_t$ | 第 $t$ 步画出来的一维剖面 |
| 屏障 | 相邻两个盆地之间剖面的最高点，决定图上显示的合并层级 |

**区间布局模型**（ST-MTM 和本文都用）：每个特征按叶序依次占据一段区间，宽度 $W_i$，相邻区间至少隔 $g$，锚点在区间中心附近；整体必须放在画布 $[0, L]$ 之内。

## 3. 三类误差指标：定义、算法和含义

### 3.1 位置误差

- 每个锚点的位移：$|x_i - q_i| / L$。
- **$E_{\mathrm{pool}}$**：所有帧、所有叶子位移的**平均值**。
- **$E_\infty$**：所有位移中的**最大值**（最坏情况）。
- **$\tau$**：某个叶序在区间模型下"能做到的最小的最坏位移"，可以由闭式算出（下一节）。图上的实际最坏位移被位置上限 $B_t = \tau_t + \beta$ 卡住。

### 3.2 排序误差 NROE

$$\mathrm{NROE}(\pi)=\frac{1}{2L}\max_{k}\Big(\max_{j\le k} q_{\pi(j)}-q_{\pi(k)}\Big)$$

**怎么算：** 沿叶序从下往上走，记住到目前为止见过的最大参考坐标；如果当前叶子的参考坐标比这个最大值小，就出现了"逆序"，逆序的幅度是两者之差。NROE 取最大的逆序幅度，除以 $2L$。

**含义：** 假设所有特征宽度为零，只要叶序是这个顺序，无论怎么摆位置，最坏位移都不可能小于 NROE。除以 2 的原因是：两个逆序的特征可以各让一半。

**好处：** 它只看顺序，与画布尺度无关，所以能直接比较 TMTM、ST-MTM 这种没有世界坐标画布的原生输出。

### 3.3 拓扑（层级）误差 $d_{\mathrm{top}}$ 与 NMLE

在画出的剖面里，两个叶子 $i,j$ 之间剖面的最高值，就是图上"显示的"合并层级 $V^\psi_{ij}$。

$$d_{\mathrm{top}}=\max_{i,j}|V^\psi_{ij}-V_{ij}|,\qquad \mathrm{NMLE}=d_{\mathrm{top}}/\Delta_F$$

**含义：** 图上任何一对特征"显示的连通水位"与"真实连通水位"之差的最大值。NMLE 是它占数值范围的百分比；实验中报告每帧的均值和全体的最大值。

**理论意义（经文献核对，D6）：** 给每个极值打上标签，$V$ 和 $V^\psi$ 就是两棵带标签合并树的"cophenetic 矩阵"，$d_{\mathrm{top}}$ 正是文献（Gasparovic 等，定义为矩阵之差的最大值；Munch & Stefanou 证明它是 interleaving 距离）中的**带标签 interleaving 距离**。

- 条件：标签要覆盖所有叶子，即剖面上不能有多余的极值。在 Ring 和 OLR 的渲染图上逐列检查过，200 列全部满足。
- 推论链：bottleneck 距离 ≤ 不带标签的 interleaving 距离 ≤ $d_{\mathrm{top}}$（分别来自 Morozov 等和 Gasparovic 等）。
- **大白话：** 层级误差不超过 $\varepsilon$ 的地图，显示的树与真实的树相差不超过 $\varepsilon$，持续图也相差不超过 $\varepsilon$。

## 4. 统一问题（论文式 3）

所有方法都可以看成在解同一个优化问题：

$$\min \sum_t \lambda_O E_O+\lambda_G E_G+\lambda_M E_M+\lambda_R E_R+\lambda_W E_W$$
约束：布局合法；$\|x_t-q_t\|_\infty\le B_t$（位置上限）；$d_{\mathrm{top}}\le(\varepsilon_0+\varepsilon)\Delta_F$（层级预算）。

| 项 | 含义 | 来自 |
|---|---|---|
| $E_O$ | 相邻时间步之间子树区间重叠的差 | TMTM |
| $E_G$ | 锚点距离相对真实空间距离的应力 | ST-MTM |
| $E_M$ | 对应锚点在时间上的运动 | ST-MTM / 本文 |
| $E_R$ | 锚点相对参考坐标的误差 | 本文 |
| $E_W$ | 区间宽度偏差 | ST-MTM |

- $\varepsilon_0$：**数据分辨率**，相差不到 $\varepsilon_0\Delta_F$ 的合并层级视为相等（float32 舍入误差）。全文取 $10^{-7}$。
- $\varepsilon$：用户愿意花的**层级预算**。

**各方法是这个问题的实例（论文表 2）：**

| 方法 | $\varepsilon$ | 位置上限 $B$ | 目标 | 求解方式 |
|---|---|---|---|---|
| TMTM | 0 | 无 | $E_O$ | 贪心翻转子树 |
| ST-MTM | 0 | 无 | $E_G+\lambda E_M$，再 $E_W$ | 先定叶序，再解二次规划 |
| $\kappa$ R20（旧方法） | 无上限 | — | $E_R+E_G+E_M$ | 候选池 + 二次规划 |
| 投影 | ∞ | $\tau_t+\beta$ | — | 按 $q$ 排序 + 二次规划 |
| 本文 | 0 或 $\varepsilon$ | $\tau_t+\beta$ | $E_R+E_G+E_M$ | 算法 1 |

**"是实例"的证据（N3 实验）：** 给定原来的叶序，两种已有方法的布局都能原样复现。
- TMTM：5 组平面数据上，由原分支选择重建的布局与官方 C++ 代码在全部 3127 个弧区间和锚点上一致，层级误差为 0。
- ST-MTM：它的锚点和区间满足其两个二次规划的最优性（KKT）条件，相对残差平面 < $10^{-6}$，三维 < $10^{-10}$。
- 两者都只在"选叶序"这一步用了近似方法：ST-MTM 的叶序在 10 帧上不是它自己目标的最优；TMTM 的贪心在 463 个穷举过的步骤中有 434 步最优，不是最优时最多差 85.5%。

## 5. 理论：定理与证明

### 5.1 引理 1（分离）——所有结论的基础

**内容：** 在层级误差 ≤ $\varepsilon$ 的地图里，如果叶子 $k$ 夹在节点 $u$ 的两个叶子 $i,j$ 之间，那么 $k$ 与 $i$ 的真实合并层级不会超过 $f(u)+2\varepsilon$。

**证明（3 行）：**
1. 图上 $i,j$ 的显示合并 = 它们之间剖面的最高点；$k$ 在中间，所以 $i,k$ 之间的最高点不会更高，即 $V^\psi_{ik} \le V^\psi_{ij}$。
2. 显示值与真实值最多差 $\varepsilon$：$V_{ik}-\varepsilon \le V^\psi_{ik}$，$V^\psi_{ij} \le V_{ij}+\varepsilon$。
3. $i,j$ 都在 $u$ 里，所以 $V_{ij}\le f(u)$。合起来：$V_{ik} \le f(u)+2\varepsilon$。

**直接推论（$\varepsilon=0$）：** $u$ 外面的叶子与 $u$ 的合并严格高于 $f(u)$，所以不可能夹在 $u$ 的叶子之间，也就是**每棵子树在图上都连成一段**。

### 5.2 定理 1（排序下界 $\nu^*$）——核心结果，对所有方法成立

记子树 $X$ 的叶子参考坐标范围为 $[m_X, M_X]$（"参考范围"）。

$$\mathrm{NROE}\ \ge\ \nu^*=\frac{1}{2L}\max_{\text{节点 }v}\ \max_{\text{兄弟 }X\ne Y}\ \big[\min(M_X-m_Y,\ M_Y-m_X)\big]^+$$

**大白话：** 每个节点下，任意两棵兄弟子树必须一前一后（因为各自连成一段）。
- 如果 $X$ 在前，$X$ 里参考坐标最大的叶子（$M_X$）就排在 $Y$ 里最小的叶子（$m_Y$）前面，逆序幅度至少 $M_X - m_Y$；
- 反过来是 $M_Y - m_X$；
- 只能选一种，所以代价至少是两者中较小的那个。
- 两个范围重叠得越深，这个最小代价越大。

**怎么达到：** 在每个节点，把子树按参考范围的**中点**从小到大排序。可以证明这样每一对兄弟都恰好选到了代价较小的方向：中点 $X$ ≤ 中点 $Y$，等价于 $M_X-m_Y \le M_Y-m_X$。于是 $O(n\log n)$ 就能算出并达到下界，不需要枚举所有叶序。

**为什么对所有方法成立：** 证明只用了"层级不错 ⇒ 子树连续"，与怎么画宽度、用什么求解器都无关。所以 TMTM、ST-MTM 也逃不掉。

**小例子（代码测试里的三叶例子）：** 叶子 A、B 先在层级 1 合并，再与 C 在层级 3 合并；参考坐标 A=20，B=100，C=60，画布 $L=120$。
- 子树 {A,B} 的范围是 [20,100]，{C} 的范围是 [60,60]；
- 代价 = min(100−60, 60−20)/2 = 20，即 $\nu^* = 20/120$；
- 如果允许层级误差 1（预算 $\varepsilon=1$），可以把顺序排成 A, C, B，排序误差变成 0，层级误差正好是 1。

### 5.3 定理 2（宽度感知下界）——适用于区间布局（ST-MTM 和本文）

特征有宽度时，大特征会把邻居推开，真正决定最坏位移的是 $\tau$。

**定义：** $\ell_k=q_k-W_k/2-H_k$（叶子能被摆到的最左端），$h_k=q_k+W_k/2+H_k$（最右端），$s_k=W_k+g$（占用长度）。对一组叶子 $S$：

$$A(S)=\max_\alpha\Big[\alpha+\sum_{k\in S,\ \ell_k\ge\alpha}s_k\Big],\qquad B(S)=\max_\beta\Big[\sum_{k\in S,\ h_k\le\beta}s_k-\beta\Big]$$

**定理：** 区间布局中，如果区块 $X$ 整体排在区块 $Y$ 前面，则 $\tau \ge (A(X)+B(Y)-g)/2$。所以每个拓扑精确的区间布局都满足：$\tau \ge$ 所有兄弟对上"两种方向中较小者"的最大值。画布两端还有与叶序无关的"装箱"下界：$\tau\ge B(\text{全部})-g$，$\tau\ge A(\text{全部})-g-L$。

**证明思路（附录有完整证明）：**
1. 从 $X$ 中任取一组 $S_X$、从 $Y$ 中任取一组 $S_Y$。$S_X$ 里最靠前的叶子 $a$ 和 $S_Y$ 里最靠后的叶子 $b$ 之间，夹着 $S_X\cup S_Y$ 的所有区间，所以两者中心至少相距"这些区间的总长度"。
2. 锚点还能各自向对方挪 $H$，所以锚点至少相距总长减去这些松弛。
3. $a$ 的锚点不能离 $q_a$ 太远，$b$ 也一样；两者的距离被"撑开"了，最坏位移至少是"撑开的距离 − 参考距离"的一半。
4. 把 $S_X$ 取成"$\ell$ 不小于某阈值的那些叶子"，$S_Y$ 取成"$h$ 不大于某阈值的那些叶子"，最大化就分解成了 $A$ 和 $B$ 两部分，用排序加前缀和就能算出。
- 宽度和间距都为零时，它退化成定理 1。

### 5.4 定理 3（链式下界）——允许层级误差 $\varepsilon$ 时

**定义：** $A_\varepsilon(u)$ 为 $u$ 的祖先中，层级不超过 $f(u)+2\varepsilon$ 的最高那个。

**定理：** 层级误差 ≤ $\varepsilon$ 时，$A_\varepsilon(u)$ 之外的每个叶子，以及所有"与 $u$ 互相都在对方 $A_\varepsilon$ 之外"的节点 $w$，都整体位于 $u$ 的一侧。对这些"必然分开"的组对套用定理 1 或定理 2 的论证，就得到排序误差和 $\tau$ 的下界。

**证明：**
1. $A_\varepsilon(u)$ 之外的叶子 $k$ 与 $u$ 的合并层级 $> f(u)+2\varepsilon$，由引理 1 它不能夹在 $u$ 的叶子之间。
2. 两组叶子如果互相都不能夹在对方之间，那么一定是一组整体在另一组前面（附录引理）。

**与粗下界的区别：** 简单的做法是把所有"与父节点相差 ≤ $2\varepsilon$"的节点一次性展平，再用定理 1。但这样一串小间隙会被当成可以一起拆开，下界很松。链式下界按间隙的**总和**计价，从不弱于粗下界。

**效果：** Tangaroa 在 $\varepsilon=5\%$ 时，粗下界平均只有 0.38%，链式宽度下界为 7.40%，实际做到 8.10%。

### 5.5 最优屏障（闭式解）

**问题：** 叶序定了以后，屏障高度怎么取，才能让层级误差最小？

**答案：** 对相邻叶子之间的第 $k$ 个空隙，令 $C_k$ = 所有跨过这个空隙的叶子对中，真实合并层级的最小值。最小可能的误差是

$$\delta^*(\pi)=\max\Big(0,\ \max_{i<j}\tfrac12\big(V_{ij}-\max_{i\le k<j}C_k\big),\ \max_k(F_k-C_k)\Big)$$

其中 $F_k$ 是空隙两边的极值，屏障不能比它们低，否则盆地会消失。取屏障 $b_k = C_k+\delta^*$ 即可达到。

**大白话：** 每个屏障都不能高于"它所分隔的叶子对里最低的真实合并层级 + 误差"，同时任何一对叶子之间至少要有一个屏障够高。把所有屏障同时取到上限，就能找到最小的误差。这正是"固定叶序下的 $\ell_\infty$ 超度量拟合"（Farach 等 1995）。

**图 5 的例子：** 顺序 A–C–B 拆开了子树 A–B。如果屏障沿用原始合并层级，误差是整个间隙 $\gamma$；用最优屏障，误差平衡到 $\gamma/2$，这是该顺序下的最小值。

### 5.6 证明是怎么核对的

- 每个下界都在随机树上与**穷举所有叶序**的结果比对过，从未出现下界高于真实最优的情况（单元测试）；
- 在零宽度情形下，定理 2 与定理 1、链式宽度下界与定理 3 逐值相等（测试）；
- 最优屏障的闭式解就是代码中 `merge_costs` 的实现，用于所有实验中的精确误差检查。

## 6. 方法：算法 1（逐帧生成地图）

输入：树、参考坐标、宽度、预算 $\varepsilon$、分辨率 $\varepsilon_0$、松弛 $\beta$、前一帧锚点。

1. **生成候选树：**
   - 原树；
   - 对每个不超过 $2(\varepsilon_0+\varepsilon)$ 的父间隙阈值，展平所有小于该阈值的节点；
   - "冲突驱动的展平"：反复找当前排序代价最大的那对兄弟，在链条件允许、且精确误差不超预算时展平。
2. **每棵候选树先按中点排序**，算精确误差 $\delta^*$，超出预算的跳过。
3. **宽度感知局部搜索：** 在每个节点内移动一个子区块到别的位置。
   - 若能降低 $\tau$，或在 $\tau$ 相同时降低"正项平方和"（用来打破平台），且 $\delta^*$ 不超预算，就接受；
   - 子节点不超过 8 个时尝试所有位置，否则只试距离 3 以内；最多 8 轮；
   - 只细化初始 $\tau$ 最小的 4 个候选和原树。
4. **选出最优叶序：** 按 $(\tau, \mathrm{NROE})$ 选，候选中包括只按点模型排出的叶序，所以结果永远不会比它差。
5. **最优屏障：** 按上一节的闭式解设置屏障。
6. **带上限的二次规划摆位：** 最小化 $E_R+E_G+E_M$（以及偏心项），约束包括宽度、间距、画布、锚点松弛和位置上限 $\|x-q\|_\infty \le \tau+\beta$。上限一定可行，因为 $\tau$ 是该叶序能达到的。
7. **报告与标记：** 输出下界、$\tau$、$\delta^*$，并标出改动超过 $10^{-3}\Delta_F$（数值范围的 0.1%）的屏障。

**为什么要位置上限：** 没有上限时，几何项会把个别锚点拉得很远（OLR 上最坏位移约 19–20%）。有了上限，$E_\infty$ 就有保证。

**验证：** 300 棵带宽度、预算随机的随机树上，搜索在 296 棵上达到 $\tau$ 的穷举最优；只用点模型叶序时为 250 棵。

**运行时间**（Apple M2 Pro，单进程）：

| 步骤 | 平面帧（1–11 个叶子） | 三维帧（最多 93 个叶子） |
|---|---|---|
| 全部下界 | ≤ 0.6 ms | ≤ 5.5 ms |
| 排序 | ≤ 3.7 ms | ≤ 103 ms |
| 带上限的二次规划（SciPy SLSQP） | 2.3–9.0 ms | 0.25–0.50 s |

917 帧全部做一遍：$\varepsilon=0$ 时 94 秒，带预算时最多 137 秒。

## 8. 比较的方法

1. **TMTM（原生）**：作者算法的输出。
2. **ST-MTM（原生）**：作者算法的输出。
3. **$\kappa$ R20（旧方法）**：本项目早期的方法，资格阈值 $\kappa/\Delta=20\%$，层级误差没有上限。三维表里还有 $\kappa$ P（拓扑精确）和 $\kappa$ R2。
4. **投影**：每帧只按参考坐标排序（类似 Hovmöller），屏障取最优值，摆位用同样的带上限二次规划。排序误差为零，但层级误差不受控。
5. **本文**：$\varepsilon=0$（拓扑精确）和 $\varepsilon=10\%$；权衡曲线上还有 1、2、5、20、50%。
6. **同模型内的 TMTM 型 / ST-MTM 型目标**：在本文的区间模型里，只换目标函数（只优化层次和时间，或只优化距离），用于地图图（图 7、图 11），保证渲染器、宽度、画布都一样，只比较"目标不同"带来的差别。

## 9. 指标汇总：怎么算、在哪展示

| 指标 | 怎么算 | 好的方向 | 展示位置 |
|---|---|---|---|
| NROE | 第 3.2 节公式，对所有帧取平均 | 越低越好，最低是 $\nu^*$ | 图 6 第一栏、图 10 柱状图、附录表 |
| $\nu^*$ | 定理 1，对所有帧取平均 | 不可避免的部分 | 图 6 黑色短线、图 10 |
| 最坏合并误差（NMLE max） | 所有帧 $d_{\mathrm{top}}/\Delta_F$ 的最大值 | 越低越好，带预算时 ≤ $\varepsilon$ | 图 6 第二栏、图 8 横轴、表 4 |
| NMLE 均值 | 每帧 $d_{\mathrm{top}}/\Delta_F$ 的平均 | 越低越好 | 正文文字 |
| $E_{\mathrm{pool}}$ / $E_\infty$ | 第 3.1 节；对所有帧和叶子取平均或最大 | 越低越好 | 图 8 纵轴、表 4 |
| $\tau$ 与宽度下界 | 叶序能达到的最小最坏位移；定理 2、3 | 越接近下界越好 | 图 9、附录表 |
| 跳动（jump） | 相邻帧中对应特征的 $\lvert\Delta x-\Delta q\rvert/L$ 的平均：图上的移动减去真实移动，即由布局造成的"假移动" | 越低越好 | 表 4 |
| 运动误差 ME | 见下 | 越低越好 | 图 6 第三栏、附录表 |
| SNS（尺度归一化应力） | 每帧 $\min_\alpha \sum(d_{ij}-\alpha\lvert x_i-x_j\rvert)^2 / \sum d_{ij}^2$，$d_{ij}$ 是支撑区域质心在二维或三维空间中的距离，再对帧平均 | 越低越好 | 图 6 第四栏 |
| TW（可信度，$k=1$） | 标准的基于排名的可信度：图上最近邻如果在真实空间里不是最近邻，按排名差扣分；对帧平均（只算叶子数 > 2 的帧） | 越高越好 | 图 6 第五栏 |
| TD | 相邻帧对应锚点位移之和（以画布宽度计） | — | 只用于核对能否复现旧值 |
| 栅格误差 | 渲染后屏障与计算值之差；锚点像素取整误差 | 越低越好 | 正文文字 |

**运动误差 ME 的具体算法**（沿用 ST-MTM 的协议）：
1. 取间隔 2 步、在两个时刻都存在的特征对。
2. 真实变化 = 两个极值点在原始空间中距离的变化。如果变化超过区域对角线的 2%，算一个"明显的靠近或远离事件"。
3. 图上变化 = 两个锚点在纵轴上距离的变化。如果变化不超过占用范围的 2%（Cylinder 沿用旧协议，用整个画布），算"漏显示"；如果方向与真实相反，算"反向"。
4. ME =（反向数 + 漏显示数）/ 明显事件数。

**可比性核对：** 用同一套代码重算旧方法存下的锚点：SNS 和 TD 的相对误差在 $10^{-5}$ 以内，TW 和 ME 只差千分位或一个事件（旧值取自渲染后的像素位置）。因此新旧数字可以直接放在同一张表里比较。

## 10. 实验与结果

### 10.1 下界验证（order_budget）
- 917 帧上，没有任何方法（TMTM、ST-MTM、本文）低于 $\nu^*$。
- **已有方法的误差大多可以避免**：Storms 上 TMTM 的 19.2% 中只有 3.8% 是层级逼出来的，ST-MTM 的 16.3% 中有 12.5% 可以避免。
- 本文拓扑精确布局在平面数据上与 $\nu^*$ 相差不超过 0.03 个百分点。在三维数据上，宽度感知排序用少量 NROE 换来更低的最坏位移（Tangaroa 9.67% 对 9.24%）。
- 所有叶子数不超过 8 的 637 帧上，预算内排序在 0 到 100% 的 9 档预算下全部与穷举最优一致。

### 10.2 横向比较（图 6，附录全数值表）
- **排序：** 投影为 0；本文贴近下界；TMTM、ST-MTM 远高于下界。
- **层级：** 投影最坏达 58.66%（Storms）、52.58%（Wildfires）、33.56%（OLR）、31.02%（Tangaroa，且没有一帧保持原树）；旧 $\kappa$ 在 OLR 和 Tangaroa 上达到同样的最坏值；本文带预算时从不超出预算。
- **运动：** 本文拓扑精确的地图在全部 7 组上都低于 TMTM 和 ST-MTM，例如 OLR 为 5.4% 对 21.4%，Tangaroa 为 52.2% 对 70.0%；投影在多数数据上最低。
- **距离：** ST-MTM 的 TW 在 7 组上都最好，SNS 在 5 组上最好；在 Cylinder 上，本文带预算的地图（0.041）和旧 $\kappa$（0.040）远低于 ST-MTM（0.135）。
- **结论：** "位置忠实"和"距离忠实"是两种不同的取舍，不排总名次。

### 10.3 位置—拓扑权衡曲线（图 8）
- $\varepsilon$ 取 0、1、2、5、10、20、50% 和投影；每个点的横轴是实测的最坏合并误差，纵轴是最坏和平均位移。
- **Cylinder：** 1% 就到了全曲线最低的最坏位移（27.00% → 5.27%），比投影的 5.73% 还低，因为投影忽略了宽度。
- **Wildfires：** 1% 时从 20.48% 降到 8.71%。
- **PM2.5：** 5% 即与投影相同。
- **Storms：** 直到 20%，最坏位移仍在 18% 以上；OLR 在 10% 以内一直是 17.14%，因为有一帧需要更大改动。
- **预算花得很集中：** 合并误差均值远小于最大值（Storms 10% 时均值 0.90%，最大 8.51%）。
- **与旧 $\kappa$ 比：** 位置水平相近时，最坏层级误差有了上限（Storms 26.07% → 8.51%，Wildfires 19.56% → 8.35%）。

### 10.4 大特征（图 9，表 4）
- Tangaroa 上只按 NROE 排序，最坏位移 20.69%，比旧 $\kappa$ P 的 16.86% 还差；按 $\tau$ 排序后，$\varepsilon=0$ 时 15.10%，$\varepsilon=2\%$ 时 14.55%，最坏帧达到下界。
- Cylinder 在 $\varepsilon\ge2\%$ 时最坏位移从 5.73% 降到 5.27%，同样达到下界。
- 代价：Tangaroa 上旧 $\kappa$ 的平均跳动更低（2.59% 对 2.82%），$\kappa$ R2 的平均位移也低于本文 2% 的地图（4.16% 对 4.55%），但它的层级误差没有上限。

### 10.5 三维中的参考方向（图 10，附录表）
- 在 Tangaroa 和 Cylinder 上各取半球 400 个方向，按原方式重建参考坐标（原方向能逐帧复现已保存的参考坐标）。
- 任何方向上原生方法都没有一帧低于 $\nu^*$（已让它们的整体朝向取最有利的一种）。
- 方向影响很大：平均 $\nu^*$ 在 Tangaroa 上为 4.70%–10.14%，在 Cylinder 上为 5.26%–28.15%。
- Tangaroa 原先选的方向（跟随特征主运动）属于代价最高的一类（400 个方向中只有 3 个更高）；改用 x 轴可从 9.24% 降到 6.09%。Cylinder 的流向轴在中位附近（7.72%）。
- 本文排序在 10 个关键方向中有 9 个与下界相差不超过 0.6 个百分点，例外是 Tangaroa 的 z 轴（2.6 个百分点，大宽度主导）。
- **用途：** 每帧算 $\nu^*$ 只需几毫秒，可以在画图之前先比较候选方向。

### 10.6 Storms 案例与误差标注（图 11）
- 同一模型内，TMTM 型和 ST-MTM 型目标的每步最坏位移平均分别为 37.3% 和 50.7%；本文拓扑精确的地图中位数 0.8%，平均 5.1%，少数几步最高 26.2%。
- 预算 10% 时平均降到 2.7%；预算只花在 118 步中的 31 步上，最多 8.51%，平均 0.90%；标出了 89 个屏障。$\varepsilon=0$ 时图上没有标记。
- **读图例子（首图那一步）：** 精确地图里 A、B 在下、E 在上，只有 C 不在应有的位置，$\nu^*=20.6\%$ 说明这一步任何精确地图都做不到更好。切到 10% 预算后，C 移到 D 旁边、位于其参考位置，这一步的四个屏障都被标出，改动最多为气压范围的 4.7%。
- **渲染精度：** 渲染后屏障与计算值最多差数值范围的 $1.6\times10^{-6}$，锚点取整最多差画布的 $2.4\times10^{-4}$（在能渲染的 Ring、OLR、PM2.5 上检查）。

## 12. 局限与待定

**论文里如实写了的局限：**
- 投影到一条线必然丢失其他坐标；在三维中，不同方向之间的冲突相差 2 到 5 倍，所以参考方向需要选择，下界可以帮助选择。
- 位置指标是对着我们自己优化的目标来量的，所以同时报告了别人的指标（ST-MTM 的距离指标、尺度无关的排序误差）。
- 没有做用户研究，"人能不能同时读出位置和嵌套、标记能否防止误读"留给后续 TVCG 工作。
- 宽度下界在大树上不是处处可以达到：Wildfires 在 $\varepsilon>0$ 时，以及 OLR 在 10% 时的一帧，最坏帧仍有差距；Tangaroa 均值约有 1 个百分点的缺口，可能来自下界本身偏松。
- 放松（$\varepsilon>0$）时被拆开的子树不再连续，"一条带对应一个连通分量"在局部失效，所以必须标记。

**还没做的：**
- 三维地图的重新渲染（需要原始体数据和 TTK 提取，仓库里没有）；
- 只允许推迟连接的单侧误差、屏障不超出数据范围的约束（D1）；
- 标题（D2）。
