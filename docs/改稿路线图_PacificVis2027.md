## 一、已完成

### 1. 全面通读与审稿式评审（10-27）✅
- 方向成立：问题是 MTM 中层次连续性与绝对空间参考之间的冲突。位置下界、最优屏障和预算查询是可以保留的骨架。
- 主要问题：
  - "统一 TMTM/ST-MTM"的说法不成立：Storms 上与 ST-MTM 的叶序一致率仅 51.7%；
  - 主表用的是 κ 启发式，没有误差上限，最坏帧 NMLE 达 19–34%；
  - NROE 用我们自己优化的 q 来度量，有循环论证之嫌；TD 惩罚的是真实运动；
  - 样本口径过多；
  - 放松的失真在图上不可见。

### 2. 三个核心问题的结论（10-27）✅
- **放松是否丢失结构**：数据层面不丢（全部极值、值和原树都保留）。地图显示的树变了，但 d_top ≤ ε 等价于标记 interleaving（ℓ∞-cophenetic）距离 ≤ ε，持续图的 bottleneck 距离也 ≤ ε。κ 版本没有这个保证，所以**删除 κ**。
- **统一表述**：在优化问题层面统一，表述为 P(Θ) = 叶序集合 Π_ε + 布局模型 + 目标项。TMTM、ST-MTM 是其中 ε=0、B=∞、λ_R=0 这一面上的实例，原文算法是这些实例的启发式求解器。
- **科学可视化定位**：写成技术论文。失真披露作为保真性的必要组成，不单独声称"设计更易读"。

### 3. 定理 A：闭式顺序下界 ν\*（10-27）✅
- 公式：ν\*(T) = max_v max_{X≠Y∈ch(v)} min(M_X−m_Y, M_Y−m_X)⁺ / 2L。在每个节点按子树参考区间中点排序即可达到，O(n log n)。
- 实现 `code/src/rgmtm/order_certificate.py`；测试 `code/tests/test_order_certificate.py`（随机树与穷举比对，包括平局情形）。
- 验证：
  - 平面 614 帧：与旧流程的枚举下界逐帧完全相同；
  - 917 帧（加上 Tangaroa、Cylinder）：TMTM、ST-MTM、P、fixed-X **违反次数均为 0**；
  - 体数据上 κ 版本 R 输出（以各帧实测 NMLE 为 ε）对定理 B **违反次数为 0**。
- 已有方法的顺序误差大多可避免：例如 TMTM 在 Storms 上 19.2% 中只有 3.8% 是保持拓扑所必需的。
- 平局：float32 输入中合并层级差约 1e-10 的情况必须视为同一层级。统一容差为 1e-7×标量范围（误差不超过该值视为零，展平父间隙 ≤ 2×容差的节点）。Cylinder 对容差敏感，见第 4 步。

### 4. ε 预算中点排序与 917 帧实验（10-27）✅
- 算法 `budget_order`：
  1. 对一组展平阈值 s（从 2ε 向下到 0）分别做中点排序；
  2. 用精确 δ\* 筛掉超出 ε 的叶序；
  3. 取 NROE 最小者。s=0 对应原树，必然可行，所以总有解。

  同时输出定理 B 的下界。
- 实验：`code/experiments/order_budget/run.py`，结果在 `code/results/order_budget20261027/`。
- 平面结果：在 ≤8 叶、可以穷举的 604 帧上，9 个 ε 档位里，与穷举最优相比只有 2 个（帧, ε）组合不是最优（OLR ε=20% 一帧，Ring ε=5% 一帧），其余全部达到最优。所有输出都满足 δ\* ≤ ε，NROE ≥ 下界。
- 体数据结果：
  - Tangaroa：ε=0 时中点排序达到 ν\*=9.24%，优于旧 P 的 9.61%；ε=20% 时降到 0.35%。但 ε 在 2–10% 之间时，结果与下界差距大（8.6 对 5.1），大树仍是弱点。
  - Cylinder：ν\* 对平局容差高度敏感（严格层级 12.24%，容差 1e-7 时 7.72%），原因是大量近退化鞍点。论文需要说明容差，或在预处理中合并这些平局。
- 与 κ 版本在相同拓扑代价下比较：4 组中有 3 组预算排序更好（例如 Cylinder R20 的 NROE 为 0.033 对 0.084，NMLE 为 1.65 对 2.81）。Tangaroa R20 是 κ 更好。
- 完整报告：`code/results/order_budget20261027/REPORT_zh.md`。

### 12. D6：核对"层级误差 = 标记 interleaving 距离"的成立条件（10-27）✅
核对的是 arXiv:1908.00063 原文。以下编号均指 arXiv 版本，期刊版编号可能不同，所以正文不写编号。

- **Gasparovic et al.：**
  - 定义 2.2：标记合并树是 (T, f, π)，其中 π: [n] → V(T) **覆盖所有叶子**；标签也可以落在内部顶点上。
  - 定义 2.6：诱导矩阵为 M_ij = f(LCA(π(i), π(j)))，**包含对角线** M_ii = f(π(i))。
  - 定义 2.13：标记 interleaving 距离**按定义**就是诱导矩阵之差的 ℓ∞ 范数。
  - 之所以称为 interleaving 距离，是因为 Munch & Stefanou 证明了它是某个带标签范畴中的 interleaving 距离（他们称之为"等距嵌入"）。
  - 定理 4.1：不带标签的 interleaving 距离等于对所有标签方式取下确界，所以 ≤ 带标签的距离。
- **Morozov–Beketayev–Weber（2013）：** 不带标签的 interleaving 距离 ≥ 持续图的 bottleneck 距离。
- **对照我们的设定：**
  - d_top 正好是 T_t 与剖面合并树（标签为同一组极值）诱导矩阵之差的 ℓ∞ 范数；
  - 对角线是极值本身的数值，剖面保持不变，所以贡献为 0；
  - 超水平集取 −f 即可。
- **唯一的附加条件：** 剖面中不能有不带标签的额外极值（否则就不满足"覆盖所有叶子"）。在 Ring、OLR 的渲染图上逐列核对：每列的局部极值个数都等于特征数，200 列中没有例外。其他数据集没有逐列核对。
- **由此得到：** d_B ≤ d_I ≤ d_I^L = d_top。论文 §3 已改写为这条链；相关工作中的表述也同步修正。
