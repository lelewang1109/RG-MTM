# RG-MTM 论文配图论证方案

日期：2026-10-23。用途：配图规划与讨论，不改变正文、图件或科学实验。以本次读取的活动 LaTeX 与 FIGURE_INDEX.json 为依据；当前图清单为12张，部分导读仍写10张。下文的“建议序号”表示未来安排，不等于当前图号。

## 1. 图要支撑的论文主张

主线：固定空间参考可能与子树连续性冲突 → 位置证书量化不可避免的偏移 → P保留层次、R选择性放松 → 最优屏障控制固定叶序的合并层级代价 → 用源场、完整序列和量化结果核对收益与代价。

需要让读者分别理解四件事：参考顺序是否正确、实际坐标偏移多少、合并阈值改变多少、源空间运动判断是否改善。这四者不能相互替代。

## 2. 参考论文及可借鉴的安排

原文：[作者项目页](https://www.csc.kth.se/~weinkauf/publications/abskoepp22.html)，[作者PDF](https://www.csc.kth.se/~weinkauf/publications/documents/koepp22.pdf)。图号结合本地原论文页面与既有全文核对。

## 4. 三张关键实验图的精确画法

### 位置证书验证与前沿

- 分解：每个数据集显示τ_free和H=τ*(T)−τ_free，纵轴统一为参考范围百分比，既展示典型分布也交代尾部。
- 验证：横轴证书预测，纵轴独立验证的位置最优值，附y=x线和残差。只有独立LP/枚举对照才可用作验证，不能画同一公式两次。
- 前沿：横轴给定标量预算，纵轴可达到的位置代价。精确前沿F、下界Φ、候选工作点使用不同线型/形状。
- 若F是各帧同预算下的均值，R工作点也应采用可比较的逐帧预算协议。当前“平均位置+跨帧最大标量”的点不能直接被解释为离平均前沿的最优性差距。
- NROE、固定顺序最优位移τ(π)、最终坐标E_pool/E_inf使用不同名称；顺序正确不等于坐标已对齐。
- 275/278帧的结论保留其原始判断协议，不把它改写成全输入或所有大树全局最优。

### 贡献消融

- “是否释放层次”：同一输入、参考、宽度、次级目标下比较P与R。
- “是否需要选择性释放”：R与自由参考排序比较；同时报告位置与标量代价。
- “屏障是否有效”：锁定同一叶序和锚点，仅改变原LCA填充/最优填充，画逐帧配对点或连线，并给y=x参考线。
- 使用当前正式实测输出，而非严格极值修正前的旧解析字段。若仅有解析预测，明确标为预测并与渲染实测分开。
- ST-MTM+固定参考是值得补的最小改动对照，但目前未核实有完整结果，不能作为已完成面板。

### 参数权衡

- 主图横轴实测NMLE，纵轴实际位置误差；κ用点标签或颜色编码。
- 同时报告序列均值和最坏帧，防止低均值掩盖局部大代价。
- P位于零合并代价参考位置；用箭头连接同一数据集的参数工作点，不连不同数据集。
- 不画“κ=20%即误差保证20%”的线或阴影。κ是放松资格阈值。
- 方向、持久性、宽度、时间权重可作为附录敏感性面板，说明结论对配置的依赖；方向必须全序列固定。

## 6. 附录与表格

附录图：所有数据完整基线地图；方向/持久性/宽度/资格阈值敏感性；SNS/TW/TD；运动窗口与投影敏感性；大树界限与精确求解范围；分阶段运行时间；基线审计；Nucleon/Benzene完整剖面；层次聚类迁移。

表格继续承担精确数值：数据协议表、参考顺序与合并代价表、连续坐标误差表、运动事件计数与区间表。正文图负责揭示趋势和机制，不必把每张表再做一次柱状图。

运行时间若只有证书子模块的64–4096叶benchmark，图题写“位置诊断耗时”，不能称端到端性能。端到端堆叠图需要预处理/提树/诊断/选序/布局/填充的完整同环境计时，目前应先核实记录。

## 7. 统一视觉协议

- 同一数据的不同方法共享时间范围、色标、显示分辨率和预处理；不对各帧单独归一化。
- 特征身份颜色与标量色图承担不同职责；叠加A/B/C标签、实线锚点、虚线参考，避免仅靠颜色识别身份。
- 三维源场使用同一相机、阈值、物理比例和投影方向；连线对应相同时间、相同特征。
- 均值与最大值同时标注；机制选帧说明选择规则。
- 二维278帧、镜像64帧、Storms744小时、Tangaroa201体、Cylinder102体及静态截面保持独立统计。
- 每张图的图注写出“展示对象—比较因素—可读结论—适用范围”，避免仅列面板名称。
