## 1. 放松方法是否丢掉了原始合并树结构？

### 1.1 保留了什么
- **全部叶子（极值）及其标量值**：放松不删除任何特征，这一点与持续性简化不同。
- **原始树 T 始终是参照**：误差以 T 为基准测量，ε=0 时输出与 T 完全一致（d_top=0）。
- **弧上样本值**：填充仍使用原始弧样本，只有屏障附近被截断或抬高。

### 1.2 改变了什么
地图上的一维剖面 ψ 有它自己的合并树 T(ψ)。放松后 T(ψ) ≠ T：
- 被展平节点的子树在地图上**不再连续**，TMTM 式"一条带对应一个分量"的嵌套读法对这些节点失效；
- 一部分点对的合并层级改变，改变量不超过 ε·Δ_F；
- 现行的双侧误差允许把合并层级**压低**，即显示出比真实更早的连接。Wildfires 的负 FRP 屏障就是这种情况，其值还超出了数据范围。

### 1.3 可以给出的严格保证（ε 版本才成立，κ 版本没有）
- d_top(ψ,T) 就是两棵**标记** merge tree（叶子身份固定）之间的 ℓ∞-cophenetic 距离。文献结论是：标记 merge tree 的 interleaving 距离等于 ℓ∞-cophenetic 距离（Munch & Stefanou 2019；Gasparovic et al., *Intrinsic interleaving distance for merge trees*，**需核对原文的定理条件**）。
- 因此，ε 版本的地图显示的是一棵与源树 **ε-interleaved** 的树。由稳定性定理，其 0 维持续图与源数据的 bottleneck 距离 ≤ ε。
- 结论表述：**"放松不丢弃结构，而是以可证明的 ε 精度近似它；ε=0 时精确保持。"** 旧 κ 版本的最坏帧误差达 19–34%，没有这个保证，这是必须删掉 κ 的根本原因。

### 1.4 与持续性简化的对照（可写进论文）
在同一个拓扑预算 ε 下有两种"花法"：
- **简化（删除）**：去掉持续性 ≤ 2ε 的特征，剩余结构精确，但特征丢失；
- **放松（重连）**：保留全部特征及其位置，合并层级的误差 ≤ ε。

两者在 interleaving 意义下属于同一量级的扰动，适用场景不同：后者服务于"特征在哪里"的任务。

### 1.5 需要决定的设计选项
- **单侧误差**：只允许抬高合并层级，不允许压低，地图永不显示比真实更早的连接。代价是误差约为双侧的 2 倍（三叶例子中为 γ 而非 γ/2）。
- **值域约束**：屏障不得超出数据范围，避免负 FRP 这类值。
- 无论选哪种，都必须**在图上标出被改动的合并层级**。

## 2. 能否用一个数学表述把 TMTM / ST-MTM 作为特例？

### 2.1 现有"统一模型"为什么不成立
它固定了我们自己的宽度规则、画布和偏心项，时间项也只是锚点代理，不含 TMTM 的子树重叠目标。所以 Storms 上它与 ST-MTM 的叶序一致率只有 51.7%，相当于随机。这是"形似"，不是"特例"。

### 2.2 正确的做法：在优化问题层面统一，而不是在求解器层面
每帧地图 M_t = (π_t, x_t, ψ_t)，即叶序、一维布局和标量剖面。一般问题记为 P(Θ)：

```
min  Σ_t  λ_O E_O + λ_G E_G + λ_M E_M(η) + λ_R E_R + λ_W E_W
s.t. M_t ∈ 𝓛_rule(π_t)                  （布局模型）
     d_top(ψ_t, T_t) ≤ ε Δ_F             （拓扑预算）
     ‖u_t − q_t‖_∞ ≤ B L                  （位置预算，可为 ∞）
```

| 项 | 含义 | 来源 |
|---|---|---|
| E_O | Σ_{u,v} (\|S_u∩S_v\| − \|I_u∩I_v\|)²，相邻帧全部子树的重叠差 | TMTM Eq.2–3（`baselines/tmtm.py: objective_between`） |
| E_G | Σ w_ij((x_j−x_i) − d_ij)²，叶锚点的应力 | ST-MTM Eq.1 |
| E_M(η) | 匹配锚点的时间项：η=0 为静止对齐（ST-MTM 的 λ 项），η=1 为跟随投影运动 | ST-MTM / 本文 |
| E_R | 锚点到参考位置的误差 | 本文 |
| E_W | 区间宽度与目标宽度的相对偏差 | ST-MTM Eq.2 |
| 𝓛_rule | (i) 样本级 DFS 线性化，布局完全由 π 决定（TMTM）；(ii) 先骨架后区间（ST-MTM）；(iii) 区间加锚点偏移（本文） | — |

子树区间 I_u 在放松后定义为其样本位置的包络；ε=0 时它与 TMTM 的定义一致。

**实例表：**

| 方法 | ε | B | 布局 | 目标 | 原文求解器 |
|---|---|---|---|---|---|
| TMTM | 0 | ∞ | (i) | E_O | 自顶向下贪心翻转（启发式） |
| ST-MTM | 0 | ∞ | (ii) | E_G + λE_M(0)，再以 E_W 为第二层目标 | 先用 OLO 选叶序（代理），再对固定叶序精确求解 QP |
| 投影 / Hovmöller 式基线 | ∞ | 0 | (iii) | — | 按 q 排序加最优屏障 |
| RG-MTM-P | 0 | 声明值 | (iii) | E_R + E_G + E_M(1) | 本文 |
| RG-MTM-ε | ε | 声明值 | (iii) | 同上 | 本文 |

**措辞：** "TMTM 和 ST-MTM 是 P(Θ) 在 ε=0、B=∞、λ_R=0 这一面上的实例；它们的算法是这些实例的特定（启发式）求解器。"这一表述是诚实的，不需要声称复现了原生输出。

**可验证：** 把原生方法的叶序 π 喂给我们对应实例的求解器，应能在数值精度内复现原生布局。TMTM 的布局由 π 唯一决定；ST-MTM 对固定叶序是凸 QP。小树上还可以穷举 π，求出 TMTM 自身目标的全局最优，量化其贪心解的差距。

### 2.3 统一不能只是"加权和"，必须带来跨方法的定理
光有上面的表述，审稿人会说任何方法都能写成加权和。真正的价值是下面这些**对整个 ε=0 面成立、因而对 TMTM 和 ST-MTM 同样成立**的结论。

**定理 A（顺序下界，闭式，已验证）。** 对任何满足 d_top=0 的 merge tree map（不论宽度规则、布局模型和求解器）：

```
NROE_t ≥ ν*(T_t) = (1/2L) · max_{节点 v} max_{v 的子树 X≠Y} [ min(M_X − m_Y, M_Y − m_X) ]⁺
```

其中 m_X、M_X 是子树 X 中叶子参考坐标的最小值和最大值。

- 证明要点：d_top=0 ⇒ 每个子树在地图上连续（由已有的 γ_v/2 引理）⇒ 兄弟子树整体先后排列 ⇒ 每对兄弟至少付出两种先后顺序中较小的代价。
- 可达性：在每个节点按子树参考区间的中点 (m+M)/2 排序，每一对兄弟都取到较小代价。所以下界精确可达，O(n log n) 即可求出，**无需枚举**。
- 意义：几何上，兄弟子树在参考轴上的区间重叠得越深，代价越大。
- 已在 596 个小帧上与穷举逐一比对，**0 个不一致**（实现：`code/src/rgmtm/order_certificate.py`；随机树穷举测试：`code/tests/test_order_certificate.py`）。

**定理 B（ε 下的必要下界）。** 若 d_top ≤ ε，则被打散的子树满足 γ_v ≤ 2ε，所以叶序在"展平全部 γ ≤ 2ε 节点"后的树 T^(2ε) 中合法，于是 NROE ≥ ν*(T^(2ε))。这一下界同样对任何方法成立。

**定理 C（区间位置下界 τ\*、τ_free、H）**：保留现有内容。它依赖布局模型（宽度、间隙），所以只对模型 (iii) 是精确的。

**定理 D（固定叶序下的最优屏障）**：δ\* 有闭式解。需要引用 ℓ∞ ultrametric 拟合（Farach–Kannan–Warnow 1995），表述为"一维叶序（Robinsonian）约束下的适配"。

### 2.6 统一公式的两处扩展（2026-10-27 第二轮）

把第一轮实验暴露的两个问题，直接写进统一公式。

**(1) 拓扑约束改为两项预算之和：**

```
d_top(ψ_t, T_t) ≤ (ε₀ + ε) · Δ_F
```

- ε₀ 是**数据分辨率**：数据精度以下的合并层级差没有意义，比如 float32 舍入、测量不确定度或数值格式的精度。
- ε 是**用户愿意花的拓扑预算**。
- 原来的隐式"平局容差"由此变成公式中的显式参数，所有定理和算法都以 ε₀ + ε 代入。

**(2) 下界改为链式的定理 C，替代定理 B：**

令 A_ε(u) 为 u 的最高祖先，且其层级 ≤ f(u) + 2ε。若误差 ≤ ε，则 A_ε(u) 之外的叶子不能出现在 u 的两片叶子之间。

- 证明：此时 (i, j) 的显示合并 ≤ f(u) + ε，但又必须 ≥ f(lca(i, k)) − ε > f(u) + ε，矛盾。
- 由此得到点对子树、子树对子树两类不可避免的代价。
- 与定理 B 的区别：定理 B 一次性展平所有间隙 ≤ 2ε 的节点，等于允许"拆开一整串嵌套子树"而不累计代价；定理 C 按链上间隙之和计价。
- 定理 C 在随机树上与穷举比对是有效下界，且总是 ≥ 定理 B（`test_chain_bound_is_valid_and_at_least_theorem_b`）。

**由此得到的新诊断量：脆弱度**

```
ν*(T; ε₀) 随 ε₀ 的下降
```

它说明层次结构的位置代价有多少来自精度以下的任意决定。Cylinder 从 12.24% 降到 6.15%（ε₀ = 1e-6），其余数据基本不变。这可以作为论文的一个发现：**保持一个不稳定的层次，是在为噪声付出位置代价。**

**算法：冲突驱动的选择性展平**

1. 从原树出发，找出当前造成最大代价的兄弟对 (X, Y)；
2. 尝试展平 X、Y 或两者，要求满足定理 C 的链条件，且精确 δ\* ≤ ε；
3. 取最优者继续，直到无法改进。

它与统一阈值展平并行运行，取较优者。效果：Tangaroa 在 ε=2% 和 5% 时被证明最优的帧数分别为 197/201 和 188/201，见 `code/results/order_budget20261027/REPORT_zh.md`。

## 3. 科学可视化语境下强调"可视化表达"是否有风险？

风险在于**过度声称**，强调本身不是问题。科学可视化论文（TMTM、ST-MTM 本身就是这类论文）的常规贡献结构是：表示与算法、有保证的视觉映射、在科学数据上的评价和案例。

**不要说：**
- "新的视觉设计更易读"——没有用户研究，这种说法站不住；
- 把编码设计当作独立的主贡献。

**应该说：**
- 地图是一种**有可证明保真度的视觉表示**：每张图都带着位置和拓扑误差的保证；
- **失真披露**是保真性的必要组成，属于 visualization integrity / faithfulness 的范畴，而不是装饰性设计。具体做法：标出被改动的屏障，配逐帧的 H 和 d_top 诊断条带；
- 交互选择 ε（可行边界与地图联动），作为方法的使用方式来写，不单列为系统贡献；
- 证据：可回溯到源数据的案例，以及（如能安排）1–2 位领域专家的简短反馈。可读性提升只作为讨论或未来工作。

篇幅建议：理论与方法约 45%，评价约 35%，可视化表示（含失真披露）约 10%，其余 10%。

## 4. 新的贡献表述（草案）

1. **一个包含已有 MTM 的统一优化表述**：TMTM、ST-MTM 是其 ε=0 面上的实例，并由此得到跨方法的定理：闭式顺序下界 ν\*（定理 A）、ε 必要下界（定理 B）、区间位置下界与层次代价 H（定理 C）。
2. **有误差上限的参考引导布局**：在 ε=0 时达到 ν\*（P 最优），在 ε>0 时用最优屏障（定理 D）以 ε-interleaving 精度近似源树，并提供可行边界和反向查询。
3. **保真披露的地图表示**：编码被改动的合并层级（可选单侧误差和值域约束）。
4. **评价**：以 TMTM 到投影基线之间的 Pareto 曲线为主结果，NROE 按"必需部分 + 可避免部分"分解，包含可控冲突的合成实验，以及 Storms、Wildfires、Tangaroa 三个案例。
