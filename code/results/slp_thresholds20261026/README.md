# 海平面气压：三个拓扑阈值的效果与缺失时间步诊断

本次为独立追加实验，不覆盖已发表的 `unified20261025` 结果或论文。

输入沿用 ERA5 海平面气压的处理场：1999-11-17 00:00 至 2000-01-14 12:00，共 118 帧，每 12 小时一帧。处理场 SHA-256 与原实验逐字节一致。地图是处理场的 Merge Tree Map 表达，不是二维地理气压场的重建。

拓扑阈值 ε = 0%、10%、20%，相隔 10 个百分点。时间轴的 10% 刻度仅用于阅读；全部 118 帧均保留，没有按时间抽样。ε 指连续标记叶对的合并层级最大误差占固定标量范围的比例，不是被删除节点的比例。该范围为 95.0809741384 hPa，因此三个允许误差分别为 0、9.5080974138、19.0161948277 hPa。阈值是上限，实际误差不必用满。

所有设置共享参考轴、区间宽度、画布、匹配、四项 QP、标量填充和同一个增补候选池。权重为参考 4、几何 1、时间 0.5、区间偏心 0.1；运动比例 η = 1。另比较位置预算 B = ∞ 与 5%。B = ∞ 时参考项仍参与优化，仅关闭位置硬上限。

| 拓扑阈值 | B = ∞ 的完整帧数 | 平均绝对参考偏移/画布 | B = 5% 的可行帧数 | B = 5% 的缺失帧数 |
|---|---:|---:|---:|---:|
| 0% | 118/118 | 6.09% | 85/118 | 33 |
| 10% | 118/118 | 4.82% | 101/118 | 17 |
| 20% | 118/118 | 4.40% | 109/118 | 9 |

B = 5% 的三个设置统计的可行帧集合不同，其平均误差不适合直接当作同一批样本的改善率。

## 缺失的两类原因与本次修正

旧有限候选池可能漏掉合法排列。原池在 B = 5%、ε = 10% 时只有 99 帧可行，本次穷举发现第 93、95 帧也可行；ε = 20% 时原池只有 106 帧，本次另发现第 37、93、95 帧可行。帧编号从 0 开始。这些是搜索漏解，不能当作全局不可行。

本数据每帧最多 8 个特征，已穷举每帧的全部排列，计算连续模型的最小位置/合并误差，并将各阈值对应的可行见证加入一个共享候选池。所有六种设置均使用这个相同的池重新求解。故新图中剩余灰列均有穷举支持的预算冲突；不宣称 QP 复合目标已对全部排列求得全局最优。

例如第 26 帧，要求所有锚点在参考位置 5% 范围内时，至少需要 28.70% 的拓扑预算，因此 ε = 20% 仍不可行。这组数据的剩余缺失来自拓扑与位置要求的冲突；自由排列的区间装箱本身没有阻止 B = 5%。

ε = 20%、B = 5% 的缺失帧为：26、32、38、42、94、101、102、107、108。没有复制上一帧或插值填补。缺失后的下一可行帧重新开始时间历史，不跨缺失帧宣称时间连续性。

## 证据与复现

`results.json` 保存完整坐标、屏障、配置、候选、逐帧穷举审计与栅格检查；`maps.npz` 保存全分辨率地图；`frame_feasibility.csv` 保存逐帧最小预算与旧池漏解记录；`manifest.json` 保存文件哈希。

本次逐一重建并检查了 649 个有效布局的区间约束、参考位置约束及叶对合并误差；全部缺失列与 NaN 掩码一致；日期连续，步长均为 12 小时；各阈值可行集合依次包含。

从 MergeTreeMaps 目录运行：

```sh
.venv/bin/python RG-MTM/code/experiments/unified/slp_thresholds.py
```

代码不改动通用求解器或历史数值证据。有限候选实验的可行性限制仍应在原论文中保留；本次针对海平面气压的穷举结论不能自动推广到更大数据。
