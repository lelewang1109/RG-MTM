# N1b 报告：宽度感知的认证叶序（2026-10-27）

运行与协议：`code/experiments/order_width/README.md`。
范围与 N1 相同：917 个时序帧，ε ∈ {0, 2%, 5%, 10%}，ε₀ = 1e-7×标量范围。只换叶序；QP、位置上限 B_t = τ_t + β 和全部度量都不变。单位为 %：E 系列、τ、跳动以画布长度归一化，NMLE 以标量范围归一化。

**要解决的问题（来自 N1）：** 在 Tangaroa 上，N1 的叶序误差（NROE）更低，最坏位移却比 κ P 差（20.69 对 16.86）。原因是：N1 按点模型 NROE 选叶序，而大体积特征的宽度会把相邻特征推开。加上限版本的最坏位移就等于 max_t τ_t + β，所以真正应该最小化的是区间位移 τ。

## 1. 方法

**定理 A_w（宽度感知的顺序下界）。** 区间模型中，叶子 k 的区间宽度为 W_k，相邻区间间隔 gap，锚点可在区间中心 ±H_k（H_k = ρW_k/2）内移动。定义：

- lo_k = q_k − W_k/2 − H_k
- hi_k = q_k + W_k/2 + H_k
- s_k = W_k + gap

若子树块 X 整体排在 Y 之前，则对 X 的任意子集和 Y 的任意子集，两者之间的距离至少是两组宽度之和，因此

```
τ ≥ (A(X) + B(Y) − gap) / 2
A(X) = max_α [α + Σ_{k∈X, lo_k ≥ α} s_k]
B(Y) = max_β [Σ_{k∈Y, hi_k ≤ β} s_k − β]
```

- 拓扑精确的地图中，每个子树连续，所以 τ ≥ 各兄弟对两种先后顺序中较小者的最大值。
- 画布两端给出与叶序无关的装箱项。
- 两项都可以排序后用前缀和求出，复杂度 O(n log n)。
- W = gap = 0 时退化为定理 A（τ = L·ν\*）；做定理 B 式展平后，对 ε > 0 同样成立。

**算法 `width_order`。**
1. 候选结构与 `budget_order` 相同：原树、各阈值展平、选择性展平。
2. 在每个结构上，从中点排序出发，对子节点排列做局部搜索。目标是 (τ, 正项平方和)，第二项用来打破 minimax 目标的平台。
3. 每一步都检查精确 δ\* ≤ ε₀+ε。
4. N1 的叶序本身也作为候选，所以每帧的 τ 不会比 N1 差。

**验证（`code/tests/test_interval_order.py`，4 项通过）：**
- 与 `interval_costs` 逐值一致；
- 零宽度时与定理 A 一致；
- 160 棵随机树与穷举比对：下界有效，叶序可行，且 τ 不超过 N1。

另在 300 棵带宽度的随机树上，与穷举最优比较：

| | 达到最优的树 |
|---|---|
| 宽度感知搜索 | 296/300（平均差距 0.003） |
| N1 叶序 | 250/300（平均差距 0.059） |
| 下界 A_w 等于最优 | 190/300 |

- **Tangaroa：**
  - ε=0 时，最坏位移从 20.69 降到 15.10，**低于 κ P 的 16.86**；
  - ε=2% 时为 14.55，与 κ R2（14.65）相当，但拓扑误差有上限（NMLE 最大值 2.00）；
  - ε=2% 时最坏帧的 τ 达到下界 A_w（13.72），即**最坏帧被证明最优**；ε=0 时离下界还差 0.53；
  - 201 帧中有 120 帧（ε=0）τ 严格变小。
- **Cylinder：** ε ≥ 2% 时最坏帧达到下界，E_∞ 从 5.73 降到 5.27，与 κ R2 持平；ε=0 时没有变化，最坏帧本来就在下界上。
- **代价：** 点模型 NROE 在 Tangaroa 上略升（9.24 → 9.67），平均位移基本不变。这正是 N1 的结论"叶序误差最优 ≠ 区间位移最优"的另一面。主表应以区间位移为主，NROE 作为辅助指标。

## 4. 结论与剩余问题

1. **N1b 完成**：在相同拓扑上限下，按 τ 选叶序后，Tangaroa 的最坏位移降到 κ P 以下，Cylinder 与 κ R2 持平，平面结果不变。N1 发现的"最坏位移不如 κ"的问题已解决，同时拓扑误差有证明保证。

   但均值并不全面占优：Tangaroa 上 κ 的跳动更低（κ P 2.59 对 N1b ε=0 的 2.82），κ R2 的 E_pool 也更低（4.16 对 N1b ε=2% 的 4.55）。论文中应如实写为"最坏位移相当或更好，拓扑误差有上限，均值略有代价"。
2. **新下界 A_w** 在拓扑精确的情形下很紧（平面 ε=0 时几乎每帧都达到），可以作为论文中"定理 A 的宽度版本"。
3. **剩余缺口（已由第 5 节的 N1b′ 处理）：** ε > 0 时，A_w 只用了定理 B 式展平，在大树上太松：Tangaroa ε=5% 时下界均值只有 0.38，而实际 τ 均值为 8.10。
4. QP 求解间隙最大约 1.2e-4（Tangaroa），与 N1 同级。

## 5. N1b′：链式宽度下界 C_w（10-27 第二轮）

**思路。** A_w 的块项只要求两组叶子"一组整体在另一组之前"。定理 C 正好给出这样的组对：

- (a) 节点 u 与 A_ε(u) 之外的任一叶子；
- (b) 两个节点 u、w，彼此都在对方的 A_ε 之外。

对这些组对套用 A_w 的块项，再加上画布装箱项，就得到 C_w（`width_chain_certificate`）。它按链上间隙之和计价，而不是把 ≤ 2ε 的间隙一次性全部展平。报告的下界取 max(A_w, C_w)，叶序与布局都不变。

**验证（新增 2 项测试，共 6 项通过）：**
- 零宽度、零间隙时，C_w 与 L × 定理 C 逐值相等（120 棵随机树）；
- 250 棵带宽度的随机树上，C_w 不超过穷举最优。

小树上的紧度（每档 150 棵树，下界等于穷举最优的树数）：

| ε | 只用 A_w | max(A_w, C_w) | 平均差距（A_w → 取大） |
|---|---|---|---|
| 0 | 98 | 98 | 0.115 → 0.115 |
| 0.2 | 101 | 105 | 0.119 → 0.102 |
| 0.6 | 74 | **101** | 0.342 → **0.088** |
| 1.5 | 104 | 107 | 0.110 → 0.057 |

**Tangaroa（201 帧）上的下界：**

| ε | 实际 τ 均值 / 最大值 | 旧下界 A_w 均值 / 最大值 | 新下界 均值 / 最大值 | 达到下界的帧 |
|---|---|---|---|---|
| 0 | 10.37 / 14.27 | 9.54 / 13.74 | 9.54 / 13.74 | 27 |

- ε=5%、10% 时，下界从几乎为零变成接近实际值。最坏帧的差距只剩 0.63 和 0.14，即**最坏位移已基本被证明接近最优**。
- 均值仍有约 0.7–1.3 的缺口，而且 ε=0 时也存在。可能的原因是块内宽度累积：A_w 只计入所选子集的宽度之和，没有计入块内必然夹在中间的其他叶子。若是这样，缺口来自下界偏松，而不是排序不够好；尚未验证。
- 最坏帧：Storms、PM2.5、Ring、Cylinder 在各 ε 下都达到下界，OLR 在 ε ≤ 5% 时达到。Wildfires ε>0 时仍有缺口（例如 ε=2% 时 7.88 对 7.22），OLR ε=10% 时缺口较大（16.31 对 5.45），这一帧需要单独检查。
