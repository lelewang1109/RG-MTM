# Tangaroa 原网格 RG-MTM 三维实验

**完整 201 帧已计算并通过独立复核。**
 
输入为官方 Tangaroa 速度场编号 0–200，每帧 XYZ=300×180×120，时间步长 0.01。在原网格计算速度模长，将 abs(v)<1e-6 替换为 1，再截断到 [0,2]，使用 TTK 0.9.9 的传统标量简化算法、绝对持久性阈值 0.2（声明范围的 10%），提取 join tree。**没有空间降采样、高斯平滑、逐帧归一化或按叶数删帧。**

本实验落实作者公开工作空间的输入语义；作者最终 Magnitude 导出文件、校验和及原二进制环境未取得，不声称与未公开文件逐字节一致，或图 15 像素级复现。此前粗网格 split-tree 试跑不与本组结果合并。

派生拓扑的复现差异：本组实际节点数范围为 36–186，论文表 1 的 10% 行报告为 50–186。两者不完全一致；差异原因尚未逐帧定位，当前不能把本组派生树称为作者最终树的精确复现。固定库版本、CPU 标量计算与未公开最终导出／运行设置均属于需要进一步核对的环节，不能据此断言某一环节就是原因。本次方法对照共享已保存、已校验的同一输入和实际树；这项差异不通过改阈值或挑帧来消除。

输入一致性补充：源第 0 帧原始速度模长最大值为 3.0590057373046875；所用帧的最大单帧标量范围为 1.99949030136（float32 为 1.9994902610778809）。完整序列对应作者工作空间记录的原始最大值 3.0590057373046875 和最大持久性约 1.9994903；这是额外的数值指纹，不代替未公开导出文件的校验和。

## 方法实现与可证明范围

- 实际树规模：每帧 36–186 个节点，18–93 个叶特征；没有 6 叶容量限制。
- TMTM 以作者工作空间的第 100 帧为焦点，向两个时间方向进行重叠优化。
- 真正多重鞍点采用明确的一维输出补充：m 个子树之间放置 m−1 个同值分隔样本；全序列额外 27 个同值鞍点副本。原始输入与 TTK 标量场不变，原样本 ID 全量核对，每个原网格样本以共享的 TTK 简化标量值出现一次。该非二叉处理是对论文二叉算法的显式实现扩展。
- RG-MTM 仍使用原连续宽度、间距、位置预算和三维几何／运动残差目标；宽度按叶弧支持体积换算，比例在全序列固定。
- 大树主问题使用连续 Pareto DP，较高元数时使用工作量下界或限时 MILP，并保留主／对偶界。**次级凸目标仅在最多 4 个声明的合法候选顺序上求解，不声称遍历所有顺序或次级全局最优。**
- 本组 RG-MTM-R 关闭可选的放松后剪枝，保留全部满足资格的放松节点；这与旧小树默认开启剪枝的试跑设置不同，需按本协议复现。
- P 主位置证书最大区间宽度为 1.98358e-10 L；所有 R 证书最大区间宽度为 0.0956105 L（L 为固定参考轴长度）。候选固定顺序凸 QP 的最大一阶差距为 2.03871e-07（目标按参考长度平方归一化）。
- 连续预算在未取整布局上检查；实际渲染锚点额外取整误差最大为 3.81427e-06 L，区间宽度的栅格误差最大为 7.61058e-06 L。渲染位置保证相应包含保存的取整误差。
- H>2% 门控：确定触发 201 帧，确定未触发 0 帧，未判定 0 帧；未判定帧保守地保持层次，不冒充精确分类。
- 固定三维参考方向 d=[0.10195406000411567, -0.9945466284062868, -0.021963004675231233]，捕获 57.686% 的匹配极值位移能量；参考值是三维极值坐标投影，不是完整三维位置。
- 2459/6925 个叶支持实例触边。匹配为计算得到的叶弧体素重叠，不是物理涡旋身份或用户感知真值。

## 本次观察

TMTM → RG-MTM-P 的平均 NROE 为 20.092% → 9.608%。本组数据中，P 改善了固定方向上的顺序保持。
P → R（20% 资格、未剪枝）的平均 NROE 为 9.608% → 0.019%，R 的实测 NMLE 均值／最大值为 14.442%／31.021%。应将位置变化与这项实际拓扑代价一起解释，不能只展示位置收益。

默认三维几何运动代理的错误率：TMTM 0.9748，P 0.5473，共享 6755 个清晰事件；其中纯内部事件 1422 个。这项结果直接评价三维接近／远离代理，不由 NROE 大小推出，也不能当作物理流场跟踪或读者准确率。

精确参考投影的 NROE 为 0，但三维代理错误率仍为 0.3050。这表明该参考投影对这些事件丢失了三维距离信息；它不是所有一维布局的通用误差下界。

NROE 是按每帧叶顺序作最优单调校准后的误差，再取时间均值；不能当作实际锚点偏移。NMLE 从完整保存的一维图中实际测量每对叶的最大间隔值，与同一输入树的 LCA 标量比较，再除以声明标量范围 2。表中层次无误差帧数指原叶间合并层级误差不超过 1e-6 的帧数。

RG 实际渲染锚点的 MAE（按参考轴长度归一化，逐帧均值后再平均）：RG-MTM-P：5.125%；RG-MTM-R 0.02：4.311%；RG-MTM-R 0.2：1.065%；RG-MTM-R 1：1.065%。TMTM 纵轴表示归一化线性化位置，RG 纵轴对应固定物理参考轴的域比例；不把 TMTM 纵轴直接当作真实物理位置。

运动比较默认 lag=2、阈值 2%；三维真值使用原物理坐标欧氏距离变化，投影真值使用同一固定参考方向。表中 n 是共享计算轨迹中的清晰事件数；完整结果另含 lag=1/2/4 和 1%/2%/5% 阈值。这些是几何判断代理，不能直接表述为读者实验或物理涡旋识别准确率。

**持久性 10% 与 RG 的 2%／20%／100% 放松资格参数不同。资格参数也不是输出 NMLE 的硬上界。**放松的实际拓扑代价以上表实测 NMLE 为准；不能仅用参考顺序改善推断完整三维运动必然改善。
