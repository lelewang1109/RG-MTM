# N1 报告：认证叶序接入区间布局 QP（2026-10-27）

运行与协议：`code/experiments/order_layout/README.md`。
范围：917 个时序帧（平面五组 614 帧、Tangaroa 201 帧、Cylinder 102 帧）。度量都在连续布局上计算，不经过栅格。单位为 %：E 系列和跳动以画布长度归一化，NMLE 以标量范围归一化。

**做法：**
- 叶序取自 ε 预算排序（拓扑误差 ≤ ε₀+ε，有证明保证）；
- 连续位置沿用原来的四项 QP（宽度、间隙、画布、偏心、参考、几何、投影运动），不做任何改动；
- "加位置上限"版本对每帧施加 B_t = τ_t + β，其中 τ_t 是所选叶序在区间几何下能达到的最小最大位移，β 是保存的 `extra_budget`。旧的 P/R 构造用的也是这一规则。

## 2. 体数据：与 κ 构造比较

| 数据 | 设置 | E_pool | E_∞ | NROE | 跳动 | NMLE 均值 / 最大值 |
|---|---|---|---|---|---|---|
| Cylinder | κ P | 5.40 | 32.08 | 12.26 | 5.87 | 0 / 0 |
| Cylinder | 新 ε=0（加上限） | **3.76** | **27.00** | **8.01** | **3.83** | 0 / 0 |
| Cylinder | κ R2 | 0.62 | 5.27 | 0.25 | 0.47 | 0.69 / — |
| Cylinder | 新 ε=2%（加上限） | 0.64 | 5.73 | **0.17** | 0.46 | 0.62 / 1.84 |
| Tangaroa | κ P | 5.01 | **16.86** | 9.61 | 2.59 | 0 / 0 |
| Tangaroa | 新 ε=0（加上限） | 4.92 | 20.69 | **9.24** | 2.73 | 0 / 0 |
| Tangaroa | κ R2 | 4.16 | **14.65** | 8.56 | 2.49 | 3.52 / — |
| Tangaroa | 新 ε=2%（加上限） | 4.49 | 20.69 | **8.23** | 2.60 | 1.48 / 2.00 |

- Cylinder：ε=0 时全面优于 κ P；ε=2% 时与 κ R2 基本相当，NROE 更低。
- **Tangaroa 是本轮发现的问题**：我们的叶序误差更低，但最坏位移比 κ 差。原因是我们按"点模型叶序误差"选叶序，没有考虑特征宽度；Tangaroa 的特征体积很大，宽度会显著影响区间位移。κ 构造是按区间位移代价 τ 选叶序的。
  - 结论：叶序误差最优，不等于区间位移最优。
  - 下一步（N1b）：在同样的拓扑预算下，从候选叶序中按 τ 选择；或把宽度纳入下界与排序。

## 3. 无位置上限的版本

无上限时，几何项会把个别锚点从参考位置拉开很远。例如 OLR 的 E_∞ 在各 ε 下都约为 19–20。所以统一公式中的位置上限 B 不是可有可无的：要保证最坏位移，必须设 B（每帧取 τ_t + β）。完整数值见各数据集 JSON 中的 `certified order, eps=*` 条目。

## 4. 结论

1. 用认证叶序替换旧候选池之后，在相同拓扑上限下，平面五组的平均位移、最坏位移和布局跳动全面改善。
2. 与 κ 版本相比：位置水平相近时，最坏拓扑误差降到 ε 以内（Storms 从 26% 降到 8.5%，Wildfires 从 19.6% 降到 8.4%）。
3. 新问题：大体积特征下，点模型叶序与区间位移不一致（Tangaroa）。这是 N1b 要解决的。
4. 未覆盖的部分：栅格渲染误差、几何与运动指标（SNS、TW、ME）的重算，留到后续步骤。
