# 顺序层面的预算实验报告（2026-10-27）

运行：`cd code && PYTHONPATH=src python experiments/order_budget/run.py`（协议见 `experiments/order_budget/README.md`）。
范围：917 个时序帧，包括平面五组 614 帧、Tangaroa 201 帧和 Cylinder 102 帧。只度量叶序误差 NROE，不涉及宽度、间隙、二级 QP 和栅格。

## 1. 定理 A / B 的逐帧检验

一个方法如果低于下界，就说明定理有错。

| 数据 | 叶数 | ν\*（%） | TMTM | ST-MTM | RG-MTM-P | 违反帧数（所有方法） |
|---|---|---|---|---|---|---|
| Storms | 1–8 | 3.767 | 19.23 | 16.28 | 3.77（116/118 帧达到下界） | 0 |
| Wildfires | 6–11 | 5.800 | 29.30 | 24.02 | 5.83（28/30） | 0 |
| OLR | 2–8 | 0.887 | 19.31 | 17.21 | 0.89（60/60） | 0 |
| PM2.5 | 1–7 | 0.971 | 12.87 | 11.60 | 0.98（364/366） | 0 |
| Ring | 1–7 | 2.656 | 7.18 | 10.39 | 2.66（40/40） | 0 |
| Tangaroa | 18–93 | 9.244 | 20.09 | 21.34 | 9.61（134/201） | 0 |
| Cylinder | 4–75 | 7.722\* | 26.62 | 17.77 | 12.26（67/102） | 0 |

- 拓扑精确的方法检验定理 A。κ 版本的 R 输出（仅体数据有逐帧 NMLE）以各帧实测 NMLE 为 ε 检验定理 B，结果全部为 0 违反。
- 平面 ν\* 与旧流程枚举得到的下界逐帧完全相同。
- \* **Cylinder 对平局容差敏感**：ν\* 在严格层级下为 12.24%，容差 1e-8 时为 11.22%，1e-7 时为 7.72%，1e-6 时为 6.15%，1e-5 时为 5.84%。也就是说，Cylinder 的 Q 场有大量几乎退化的鞍点（合并层级差 ≤1e-6）。其余六组数据在 0 到 1e-5 的容差范围内 ν\* 不变。论文必须说明平局容差，并给出这一敏感性。
- 已有方法的可避免误差（NROE − 下界）占大头。以 TMTM 为例：Storms 15.5、Wildfires 23.5、OLR 18.4、PM2.5 11.9、Ring 4.5、Tangaroa 10.8 个百分点。

## 2. ε 预算中点排序

每格为：平均 NROE / 定理 B 下界 / 在可穷举帧上达到穷举最优的帧数。单位 %。

| 数据 | ε=0 | ε=2% | ε=5% | ε=10% | ε=20% |
|---|---|---|---|---|---|
| Storms | 3.77 / 3.77 / 118 of 118 | 2.98 / 2.89 / 118 | 2.21 / 1.50 / 118 | 1.43 / 1.13 / 118 | 0.89 / 0.10 / 118 |
| Wildfires（19 帧可穷举） | 5.80 / 5.80 / 19 | 2.74 / 2.12 / 19 | 2.13 / 1.17 / 19 | 1.26 / 0.28 / 19 | 0.28 / 0.04 / 19 |
| OLR | 0.89 / 0.89 / 60 | 0.59 / 0.59 / 60 | 0.41 / 0.41 / 60 | 0.30 / 0.00 / 60 | 0.27 / 0.00 / **59** |
| PM2.5 | 0.97 / 0.97 / 366 | 0.34 / 0.22 / 366 | 0.00 / 0.00 / 366 | 0 | 0 |
| Ring | 2.66 / 2.66 / 40 | 1.51 / 1.41 / 40 | 0.78 / 0.48 / **39** | 0.05 / 0.00 / 40 | 0 |
| Tangaroa（无可穷举帧） | 9.24 / 9.24 | 8.64 / 5.11 | 8.20 / 0.19 | 7.48 / 0.00 | 0.35 / 0.00 |
| Cylinder（34 帧可穷举） | 8.01 / 7.72 / 34 | 0.21 / 0.05 / 34 | 0.10 / 0.00 / 34 | 0 | 0 |

- 每个输出都满足 δ\* ≤ ε（运行时有断言检查）。
- 在可穷举的帧上，9 个 ε 档位中只有 4 个（帧, ε）组合不是最优：OLR ε=20% 一帧、Ring ε=5% 一帧、Cylinder ε=0.5% 两帧。其余全部等于穷举最优。
- **Tangaroa 是弱点**：ε 在 2–10% 之间时，我们的结果与定理 B 下界相差很大（8.6 对 5.1，8.2 对 0.2），无法判断是下界偏松还是算法偏弱。这里需要更好的大树算法，或更紧的下界。

## 3. 与 κ 版本在相同拓扑代价下的比较（体数据）

做法：把 κ 输出每帧的实测 NMLE 作为 ε，交给预算排序。

| 设置 | κ：NROE / NMLE | 预算排序：NROE / NMLE | 预算更好 / 更差的帧数 |
|---|---|---|---|
| Tangaroa R2 | 8.56 / 3.52 | **8.27 / 3.40** | 60 / 6 |
| Tangaroa R20 | **0.019** / 14.44 | 0.151 / 14.41 | 8 / 3 |
| Cylinder R2 | 0.249 / 0.69 | **0.216 / 0.59** | 7 / 1 |
| Cylinder R20 | 0.084 / 2.81 | **0.033 / 1.65** | 8 / 0 |

在相同的拓扑预算下，预算排序多数情况下更好，而且误差有上限保证。Tangaroa R20 是例外：κ 版本的候选搜索在高预算下排出了更好的叶序。

## 4. 结论与后续

1. 定理 A、B 在 917 帧上没有反例。P 改用中点排序后就能达到 ν\*；旧流程的 P 在 Tangaroa 上平均高出 0.36%，在 Cylinder 上高出 4.5%（按容差 1e-7 计）。
2. ε 预算排序在中小树上基本精确最优，是删除 κ 的直接替代。
3. 待解决：
   - 大树（Tangaroa）在 2–10% 预算下的最优性差距；
   - Cylinder 的近退化鞍点：是否在预处理中合并平局；
   - 把这些叶序接入区间布局 QP，得到真实位置误差（路线图 N1）。
