# 代码数据入口

`real -> ../../data/real`，`public_scalar -> ../../data/RG-MTM-public-scalar`。小型地理叠图资产保留在 `geo/`，不参与数值实验。

当前输入清单见 [共享数据说明](../../data/README.md)。二维/三维协议与获取命令分别在 `experiments/publication2027/`、`experiments/volume3d/`、`experiments/paper1_suite/`。

Nucleon 是二维静态切片；Benzene 是明确标记的二维电势重建版；Cylinder 为完整102帧三维方柱数据。旧“Cylinder未运行”及旧Benzene电子密度说明已由正式结果替代。获取完整处理参数请使用对应冻结协议，不从历史讨论推断。
