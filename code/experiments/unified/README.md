# 统一位置—拓扑模型实验

当前论文主线：在现有四项布局公式中，通过权重、时间目标和真实误差预算表达不同设计原则。所有工作区域使用同一变量、区间几何、QP、标量填充和屏障修正；原生基线只用于独立比较。

| 区域 | 参考权重 | 几何权重 | 时间目标 η | 拓扑预算 ε | 位置预算 B |
|---|---:|---:|---:|---:|---:|
| 拓扑—时间，TMTM-inspired | 0 | 0 | 0 | 0 | ∞ |
| 拓扑—几何，ST-MTM-inspired | 0 | 1 | 0 | 0 | ∞ |
| 参考保持 | 4 | 1 | 1 | 0 | ∞，或用户给定 |
| 参考放松 | 4 | 1 | 1 | 0.02 / 0.10 | ∞，或用户给定 |

时间项权重统一为0.5，偏心项为0.1。η=0表示对齐上一帧显示位置；η=1表示跟随真实参考位移，代码也支持中间值。关闭参考项时同时关闭位置硬约束，避免隐含参考牵引。

每一候选顺序先计算真实连续合并误差与位置可行性，再用同一个四项QP优化。若主目标有自由方向，在其零空间内用共同的紧凑布局规则确定位置，保持主目标值与预算不变。四叶以内穷举；更大帧采用结果中记录的确定候选池。每帧的池在所有配置间相同，池外最优性不作保证。按前一帧布局顺序求解，不宣称全时序最优。

从项目根目录运行：

    PYTHONPATH=RG-MTM/code/src .venv/bin/python RG-MTM/code/experiments/unified/run.py
    .venv/bin/python RG-MTM/code/experiments/unified/export.py
    PYTHONPATH=RG-MTM/code/src .venv/bin/python -m unittest discover -s RG-MTM/code/tests -v

普通Python环境可安装code/pyproject.toml的依赖，再将解释器改为python。从仓库code目录运行时使用：

    PYTHONPATH=src python experiments/unified/run.py

结果在results/unified20261025/。五组数据614帧，每帧五种设置，共3,070个主实验布局；Ring另有3×3双预算矩阵（含三组已计算设置，共360次查询）。原生TMTM/ST-MTM只在Ring和Storms重新运行，与对应启发区域作描述性比较。相似性只拟合一个全序列仿射变换，可含整体镜像，不逐帧拟合。

每组保存完整输入、候选池、配置、坐标、QP目标与一阶间隙、连续屏障、实际栅格误差以及地图NPZ。统计来自完整坐标和屏障；缺失列表示没有找到满足双预算的候选，不继承上一列，也不放宽阈值。严格极值间隔产生的额外标量误差单独记录。

正文图16为原生方法与统一模型区域对照；图17为双预算图矩阵。SVG与生成代码是新增图的可编辑源。原图1—14的PPT合集保持其既有范围。

TMTM-inspired采用特征锚点对齐代理，并非原论文的全部子树重叠目标；ST-MTM-inspired保留距离应力与时间锚定思想，区间宽度、归一化和排序仍使用本体系的统一规则。视觉相似程度由结果说明，不作原算法等价承诺。
