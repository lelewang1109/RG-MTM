# Reproduce the RG-MTM experiments

Run all commands from the repository root. Use Python 3.10 or later; dependencies
are pinned in `pyproject.toml`. There are three different workflows below.
Rebuilding figures from saved evidence is not a new raw-data experiment.

## 1. Install and verify the committed snapshot

```sh
git clone https://github.com/lelewang1109/RG-MTM.git
cd RG-MTM
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
PYTHONPATH=src python -m unittest discover -s tests -v
PYTHONPATH=src python experiments/publication2027/validate.py
```

The validator checks source and result hashes, table and figure provenance,
active dataset membership, and numerical manuscript claims. The tests compare
certificates with independent optimizations and check native scalar barriers,
preprocessing contracts, and undefined-event handling.

## 2. Rebuild tables and figures without raw observations

```sh
PYTHONPATH=src python experiments/publication2027/build.py
PYTHONPATH=src python experiments/publication2027/validate.py
```

This uses committed JSON/CSV evidence and derived figure arrays, including the
ERA5 and OLR processed render exports. It regenerates paper tables and
PDF/PNG/SVG figures, grouped result snapshots, and provenance manifests.
Figure file hashes can change when a renderer embeds timestamps; run the builder
before validating newly regenerated files. Scientific algorithms and raw inputs
are not modified by this workflow.

The executed five-leaf filling example verifies all 120 leaf orders, named
ordinary-node/merge-node pixel correspondences, and optimal-budget feasibility.
It is a synthetic method validation, not an additional real-data sequence.

## 3. Recompute scientific experiments

Prepare real inputs as documented in [`data/README.md`](../../data/README.md).
Local input directories and downloaded reference PDFs are excluded from Git.
Ring and Gaussian fields are generated by repository code.

```sh
# Synthetic-only run; does not need the real input files:
PYTHONPATH=src python experiments/publication2027/run.py --datasets ring

# Five default stages on the five active planar sequences:
PYTHONPATH=src python experiments/publication2027/run.py

# Explicit full ten-stage chain (exact enumeration can be expensive):
PYTHONPATH=src python experiments/publication2027/run.py --stages replicate evaluation attainable filling robustness pointcert persistence witness_stats result_tables native_merge_errors

# Refresh publication evidence after any numerical rerun:
PYTHONPATH=src python experiments/publication2027/build.py
PYTHONPATH=src python experiments/publication2027/validate.py
```

The default five stages are evaluation, filling, point certificates, result
tables, and native merge errors. Each run records dataset/stage selections,
runtime, exit codes, and hashes in `results/publication2027/runs/`. A failed stage
stops the run. Run writers sequentially; they share result files.

The committed completed run covers 30 dataset-stage executions. Replication,
exact-frontier, scalability, and sensitivity records are separately identified
retained evidence. Newly redrawn figures do not relabel these as new numerical
runs. Results concern processed fields and computed tracks; the motion proxy
is not a participant study.

Use `PYTHONPATH=src python tools/build_rgmtm_figures.py` for current figures, and `PYTHONPATH=src python tools/verify_rgmtm_migration.py` to verify numeric integrity, reversible historical hashes, and image manifests. Prior run manifests retain their original hashes and method keys; they do not claim the renamed code was rerun.
