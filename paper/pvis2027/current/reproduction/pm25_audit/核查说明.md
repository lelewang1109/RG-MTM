## 3. 老师表1：TMTM/ST-MTM描述核查

这里核对的是老师tables/table_family.tex的方法分类表，不是学生稿目前的数值结果表1。

**TMTM：需要修改“no optimization”。** 原文3.2节明确通过贪心优化遍历顺序匹配相邻帧的子树重叠；所以不能笼统称为没有优化。建议整行写成：

- Order rule: Greedy child-traversal optimization to match inter-frame subtree overlaps.
- Placement: Sample-count-based packing; no separate continuous anchor-position optimization.
- Allowed merge error: 0 (exact simplified-tree model).
- Axis: Hierarchy-constrained traversal coordinate.

“children by overlap with the previous frame”方向上正确，但应表述为相邻/参考帧，因为算法也可从起始帧向前回溯。

原文：https://www.csc.kth.se/~weinkauf/publications/documents/koepp22.pdf ，3.2–3.2.1节。该文还明确承认采用贪心优化，因此这里应区分顺序优化与连续位置优化。

**ST-MTM：与本地实现一致的确切表述为：**

- Order rule: Hierarchy-constrained OLO, with temporal concordance and ratio-thresholded reordering.
- Placement: Pairwise distance stress plus a matched-anchor temporal penalty; followed by interval allocation and discretization.
- Allowed merge error: 0 (model target; rendered numerical tolerance requires separate checking).
- Axis: Relative-distance layout coordinate, without a fixed physical origin or direction.

本地choose_temporal_order并非简单“保留上一帧叶序”：先根据匹配构造当前树的时间一致顺序，再与OLO比较；当C_OLO/C_concordant <= r时采用OLO，否则保留时间一致顺序。0/0时本地实现定义为1。位置目标中时间项只针对有匹配的锚点，不是所有叶子都使用上一帧锚点。还应提及后续区间分配，避免把叶锚点目标函数等同于完整映射算法。

核查依据：RG-MTM/code/src/rgmtm/baselines/stmtm.py的choose_temporal_order、project_leaf_anchors及模块流程说明。此项细节已与本地实现核实；SSRN原文下载本次返回403，不能声称已经重新逐式核对作者原文。原文入口：https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6604235 。若要把ratio阈值及全部公式标注为“原文已逐式确认”，仍需可读的作者PDF。建议老师表1采用上述机制描述，0/0约定保留在实现说明中。
