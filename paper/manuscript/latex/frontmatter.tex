\hypersetup{pdftitle={Reference-Guided Merge Tree Maps: A Unified Position--Topology Framework}}
\abstract{
Temporal scalar maps must balance hierarchical connectivity, spatial geometry, temporal continuity and absolute reference position. We express these requirements within a unified position--topology framework using one interval representation, four-term quadratic layout and source-value renderer. Objective restrictions define topology--time and topology--geometry regimes inspired by TMTM and ST-MTM; enabling reference guidance and bounded topology relaxation extends these design principles within the same model. A scalar allowance limits labelled merge-level discrepancy, while an independent position allowance limits reference displacement. Positional certificates and optimal fixed-order barriers explain the feasible trade-offs and support inverse threshold selection. New experiments recompute five operating settings on common planar temporal inputs, compare inspired outputs descriptively with native baselines, and show maps across both budgets. An independent exhaustive/candidate budget sweep verifies continuous feasibility and monotonic frontiers. Retained temporal, volumetric and static studies expose practical benefits and limits. The contribution is a controllable design space with measurable errors, explicit search coverage, and a clear distinction between shared design principles and native-algorithm equivalence.

}
\keywords{Temporal scalar fields, merge tree maps, reference-guided layout, unified layout models, positional certificates, merge-level distortion.}
