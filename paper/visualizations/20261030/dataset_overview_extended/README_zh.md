# 五组总览：条状剖面、六档参数和三维包围盒（2026-10-30）

## 图中约定

- 五组：Storms、Wildfires、PM2.5、Tangaroa、Vortex。
- 每行从左到右：源空间快照、ε=0 的单列剖面、ε=0%、2%、5%、10%、20%、30% 的同一时间窗地图。
- 同一条跟踪特征在窗口起点、快照帧、窗口终点，按时间顺序编号 A1、A2、A3。因此左侧快照和剖面对应 A2；各参数列中的同号点严格对应同一时间和同一跟踪 ID。不是不同叶子或重新匹配的特征。
- 剖面圆点为实际映射位置，白色菱形为其空间参考点 q，短线连接二者。各参数图中也保留 A2 的 q 菱形。
- 金色窄框是左侧快照帧的完整一维剖面列 [t-0.5,t+0.5]×[0,1]，而非任意绘制的局部空间块。白色竖虚线已取消。黑色参考轨迹虚线保留。

## 颜色核对与修正

上一版 Tangaroa 地图使用 viridis，Vortex 地图使用通用 RdBu_r；因此上一版并非两幅原三维图的精确颜色映射。

本版：
- Tangaroa：恢复原体渲染 transfer_function_points 的 RGB，按原 speed∈[0,2] 归一化。地图、0% 剖面和体渲染使用同一套颜色来源，不再出现 viridis 的绿色。体渲染额外有透明度，因此与不透明地图的视觉明度仍可能不同。
- Vortex：逐点采用原 `volume_render.py` 的 TF RGB，显示变换仍为 raw=-2*canonical_join；范围为原图 evidence.json 的 [-1.5,1.0]，并沿用原图对 -1 以下部分的颜色定义。地图、剖面和三维体渲染的颜色来源一致。
- PM2.5：改为蓝—青—浅黄—橙—红的高对比色阶，整个窗口的六档图与左侧快照统一使用固定 [12,80] 的显示范围，无逐列自动拉伸。改变的是显示，不是原始浓度或布局。
- Wildfires：保留上一版暖色及固定 gamma=0.65，六参数共用同一范围。

## 三维空间

- Vortex：使用原 128³ 体渲染缓存和同一正交相机，投影实际体素域的 12 条包围盒边。
- Tangaroa：从 t=100 的原 scalar_100.npy 重新体渲染，保留原 RGB/透明度传递函数，改用斜视相机以展示顶面、侧面及完整三维包围盒。原始数据域是长方体（x=1、y=0.6、z=0.2），没有人为拉成等边立方体。
- Tangaroa 相机 look_from=(1.3,-1.4,0.5)、look_to=(0.15,0,-0.4)、up=(0,0,1)，平行投影 aspect=1.2；320 像素源图。A2 的投影由原三维坐标求得，八角点投影变换核验误差 <1e-10。

## 新增 30% 的来源与核验

前四组此前没有 30% 的当前方法结果，因此新增求解：Storms 从第 0 帧至 53，Wildfires 至 27，PM2.5 至 187，Tangaroa 至 120，共 391 个新布局。保留从首帧开始的完整时间优化历史，只截取目标窗口进行标量剖面渲染。没有从 20% 结果插值、换用 κ 输出或在窗口起点重置优化。

30% 前缀的最大实际归一化合并误差分别为 28.7014%、27.6485%、5.6164%、29.9036%，均在预算内。新增布局的区间不重叠、锚点约束、位置上限、实际合并误差和栅格填充误差均核验；最大归一化区间约束违反在 1e-16 量级。详见 epsilon30_verification.json。数值求解器曾输出 BLAS 浮点警告，但保存的解及独立逐元素约束检查均为有限值并通过上述核验。

Vortex 30% 使用已有从第 0 帧开始的 90 帧独立核验结果 `output/vortex_teaser_3d_v4_20261030/epsilon30/vorts/`。

所有地图继续只做双线性显示插值；A1/A2/A3 和轨迹取实际逐帧锚点，不产生新观测帧，也不修改真实跳动。

## 文件与复现

- dataset_overview_extended.pdf / .svg / .png：交付图。
- manifest.json：同号点时间、跟踪 ID、参考坐标、剖面点、框选范围及实际误差。
- epsilon30_verification.json：新 30% 布局独立检查。
- tangaroa_oblique.npz：新斜视体渲染及投影缓存。
- source/epsilon30.py：新增 30% 求解入口，每次传一个数据集名。
- source/build.py：组合图件，冻结六参数和配色。

从工作区根目录运行 `.venv/bin/python output/dataset_overview_extended_20261030/source/build.py`。旧版图保留原目录。此次仅更新独立图件。
