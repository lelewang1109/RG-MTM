# 二维 Storms 首图：特征支撑与位置参考表达改进

本轮只修改二维 Storms，保留原文件；新文件是 `ppt/Storms_feature_support_improved.pptx`，预览是 `Storms_feature_support_improved.png`。

从原可编辑 PPT 导入后进行局部修改，保留尺寸、字体、场值图像、标量配色、五档预算、匹配 ID、位置锚点和原生树图：

- 五个空间快照叠加 A/B 的实际叶特征支撑采样集合，用淡色填充和轮廓表示，避免只有一个点导致“按位置追踪网格粒子”的误解。
- 匹配支撑是代码中的 `leaf_feature_vertices`，包括极值顶点和所属叶弧 regular vertices；不等同于手绘低压范围或外部验证的气旋区域。
- A/B 的跨帧身份由相邻帧支撑集合的全局一对一重叠匹配固定；圆点仅表示极值或显示位置，参考菱形 q 是极值位置的固定方向投影。
- 删除 40 处重复参数/时间索引，将其余 40 处实例编号简化为 A/B。颜色、时间轴和参数列承担对应关系，关键帧标签保留。
- 在五档局部地图上新增完整参考轨迹 q(t) 的同色虚线，与原来的显示轨迹 x(t) 实线对照；现有参考菱形及偏移连接段保留。
- 底部明确 t=236 的实际合并误差：0%、0%、1.07%、1.07%、3.08%。结构层数继续保留，不能当作压力差或预算使用量。
- 原来完整树的所有原生分支坐标保持不变。支持区域仅替换五幅科学快照图像，文字、点线、参考曲线和树保持原生可编辑对象。

填色区域=匹配支撑；空间圆点=极值代表；剖面圆点/实线=显示位置 x；菱形/虚线=参考位置 q。轨迹的上下变化包含参考位置变化及布局残差，不能直接解释为物理气旋运动。

核验数据在 `verification.json` 与 `.build/support_evidence.json`；导出验证在 `.build/validation.json`。

绘图脚本 `source/support_panels.py` 从保存的小时数据读取真实支撑集合。PPT 编辑脚本为 `.build/edit.mjs`，基于原 PPT 导入并编辑；输出文件按最终化流程另存。未改动论文或三维 PPT。
